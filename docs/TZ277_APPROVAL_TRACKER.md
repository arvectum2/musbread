# TZ-277: контроль письменных согласований

Исходный пункт 2.2.3.9.2, строка 330 ТЗ закупки 0372200172326000015.

**Только черновик. Никакие вопросы заказчику не отправлены.**
Источник вопросов: [279 отдельных строк](tz-audit/CUSTOMER_RFI_QUEUE.csv) в десяти рабочих пакетах.

## Операционный порядок

1. После заключения согласовать официальный канал и ответственного музея.
2. Зафиксировать подтверждённую дату фактического получения запроса музеем (МСК).
3. Для контроля двух рабочих дней вести приватный CSV с колонками rfi_id;received_date;response_date.
4. Отдельно передать согласованный календарь нерабочих дат в формате YYYY-MM-DD (по строке на дату).
5. Запустить Python-скрипт check_museum_response_sla.py с явным календарём и отчётной датой.
6. При отсутствии ответа не считать вопрос утверждённым; показать статус WAITING/OVERDUE.

Команда: python3 scripts/check_museum_response_sla.py PRIVATE.csv --holidays PRIVATE_HOLIDAYS.txt --asof 2026-10-20

Реальные письма, персональные данные, контакты и ответы не помещать в публичный Git. Процедуры изменения договора подчиняются 44-ФЗ. До подписания контракта срок ответа по TZ-277 не наступил.
