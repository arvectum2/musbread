# Решение исполнителя: оставить существующий билетный сервис ВМузей

**19 октября 2026 · закупка 0372200172326000015.** Дизайн временно на паузе. ТЗ 2.2.3.2 и 2.2.3.6.4 (TZ-079, TZ-198, TZ-205).

## Утверждённый подход

На текущем официальном сайте `muzei-xleb.ru` билетные ссылки уже ведут на внешнюю площадку:

**https://vmuzey.com/museum/sankt-peterburgskiy-muzey-hleba**

По решению исполнителя оставляем **именно этот прямой переход**, без собственного checkout, платёжной формы, API, webhooks, хранения банковских данных, нового оператора или дублирования каталога билетов. Передача платёжных данных и весь процесс покупки остаются у ВМузей. В нашем Next.js `museumReference.ticketUrl` содержит исходный URL, он используется в **десктопной шапке, мобильном меню, английской шапке и на странице билетов и льгот**. В старом исходном музейном HTML эта же площадка указана в меню посетителей и на странице правил «Пушкинской карты». Существующие оригинальные цены музея и правила льгот остаются локальными исходными текстами; чужой прайсинг не выдумываем.

## Контроль

- Адрес оригинального музея через Mac mini доступен, возвращает HTTP 200; архивированные официальные страницы содержат тот же внешний URL.
- URL ВМузей HTTP 200, но прямой автоматический GET показывает **KillBot user verification**. Это не доказательство наличия всех позиций и успешного платежа; автоматизировать обход защиты не нужно.
- Браузерный E2E локального Next.js проверил переходы по точному URL в десктопной шапке, мобильном меню и разделе «Билеты и льготы», `target=_blank`, `rel=noopener` и `rel=noreferrer`, без встраивания платежей. **2 теста PASS**.
- Редактирование дизайна **не проводилось**.

| TZ-198, интеграция билетной системы | 🔴 | 🟡 | Сохранён ровно существующий официальный переход; отдельный API **не требуется** по принятому решению, но внешний checkout пока не верифицирован |
| TZ-205, продажа билетов по прейскуранту | 🔴 | 🟡 | Тарифы музея перенесены; полный ассортимент входных билетов, экскурсий, событий и остальных платных позиций на внешней площадке не подтверждён из-за антибот-проверки |

**Новый счётчик по 325 ТЗ: 🟢 84 / 🟡 105 / 🔴 136; открыто 241.** Других требований это решение не отменяет. После договора достаточно ручной проверки того, что внешний сервис продолжает оформлять нужные билеты. Если конкретные позиции у ВМузей отсутствуют, это вопрос к билетному оператору и заказчику, а не основание заранее писать новое платёжное ПО.
