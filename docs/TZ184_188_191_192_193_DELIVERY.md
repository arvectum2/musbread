Контроль авторизации MoonShine и ACL по разделам, никаких внешних вызовов/ИИ/отправки файлов. Подсказка не сохраняется, пока человек не проверит её по изображению и не загрузит файл. Публичный индекс исходного демо по умолчанию запрещён. | Письменное решение об индексации, согласование DNS/домена и проверка опубликованного реального файла. **Частично.** |

## Проверки

- `MuseumAltDraftTest` — 3 теста: генерация от подписанного контекста без сохранения, запрет бессмысленного текста, запрет доступа редактору к чужим разделам. Никакой `alt` не генерируется из необследованного бинарного изображения и не публикуется без подтверждения.
- `MuseumDocumentsTest` — регресс защищённой библиотеки с форматами и XLS; `MuseumMediaTest` — приватный предпросмотр/ACL/WebP/alt и публикация только проверенных байтов.
- `npm run test:seo` — 3 теста: маршруты CMS/афиши, 2 режима robots/sitemap, несуществующий или опасный путь блокируется.
- `npm run build`, аудит проставления alt и предконтрактного `noindex/robots`, браузерный прогон и полный PHP/Next.js CI.

Новых юридических текстов, сторонних сервисов распознавания, внешней отправки изображений или боевой публикации не создавалось. Условия лицензирования TinyMCE не изменены. Текущая матрица оставляет все перечисленные пункты **«Частично»** до согласования и приёмки музея.
