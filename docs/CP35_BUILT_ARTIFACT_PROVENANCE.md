# CP-35D — фактический состав сборки и ограничения лицензий

Дата: 16.10.2026. Предконтрактная подготовка сайта Музея хлеба, закупка №0372200172326000015. Рабочая локальная сборка на Mac mini. **Это не проверка серверов музея, не лицензионное заключение и не акт передачи прав.**

## Разграничение трёх способов поставки

1. Публичный сайт: заранее собранный статический Next.js export без PHP, CMS, Composer vendor, секретов и Node modules в публичном каталоге.
2. Закрытая CMS: установленные Composer-библиотеки PHP, опубликованные отдельно в public/vendor/moonshine* статические JS/CSS/WOFF2, доступ только с защищённого внутреннего контура.
3. Предконтрактный ZIP: только зафиксированные Git HEAD исходники и документы; установленный vendor и собранный Next.js не включаются.

Lockfile SBOM из CP-34D охватывает 560 записей, но не доказывает, что все опциональные libvips, Node dev tools, нативные библиотеки и backend-бинарники входят в конкретную поставку.

Для CMS проверяются каждый опубликованный статический ресурс, версии Composer по installed.json и lock, SHA-256 деревьев каждого из 116 установленных пакетов; библиотечный исходный код не выгружается в результаты. Сопоставление минифицированных JS-файлов с точной транзитивной npm-лицензией ещё НЕ доказано.

## Выявленные риски

- **TinyMCE:** физически установленная версия 7.2.1; GPL-уведомление присутствует. Даже при включении опционального html-source редактора сам PHP-пакет и JavaScript TinyMCE остаются в установленной сборке. Для полной замены требуется отдельное юридическое/техническое решение, удаление пакета/ассетов и повторный аудит. См. GitHub issue #24.
- **Gilroy:** пять WOFF2 обнаружены и учтены в инвентаре. Нет подтверждения права конечного распространения для конкретной поставки. Это незакрытый вопрос, не автоматическое доказательство нарушения. Подтвердить лицензии или заменить шрифты с проверенными правами.
- **Nginx:** прежняя закрытая CMS-конфигурация отклоняла весь /vendor/, включая необходимые MoonShine JS/CSS/WOFF. Исправлено: разрешены только известные namespace /vendor/moonshine/ и /vendor/moonshine-tinymce/ со статическими расширениями на loopback listener 127.0.0.1:18082. Остальные vendor, PHP, dotfiles и sourcemaps блокируются. Публичный сайт по-прежнему запрещает /vendor/.
- **MoonShine bundles:** Composer lock не подтверждает индивидуальные лицензии всех JS/WOFF2, вложенных в UI пакеты; они требуют отдельной проверки notices.
- **Нативная Linux-среда:** конечные PHP-FPM, Nginx, библиотеки ОС и ресурсы хостинга заказчика не входят в локальный SBOM.

## Проверка и воспроизводимость

Аудитор scripts/audit_built_artifacts.py запускается именно ПОСЛЕ сборки в трёх независимых режимах:

    python3 scripts/audit_built_artifacts.py --mode web --out /tmp/musbread-cp35-web.json
    python3 scripts/audit_built_artifacts.py --mode cms --out /tmp/musbread-cp35-cms.json
    python3 scripts/audit_built_artifacts.py --mode source-zip --zip /tmp/musbread-preaward.zip --out /tmp/musbread-cp35-zip.json

Вывод содержит хеши и технические метаданные. Компiled bundle хеши Linux и Mac не обязаны совпадать, поэтому JSON фактической сборки не коммитится в качестве фиктивно универсального доказательства. GitHub Actions сохраняет три JSON-аудита артефактами на 7 дней; исходные библиотеки и клиентские ПДн в отчёты не копируются.

Тесты охватывают повреждённую версию Composer, исчезновение GPL-уведомления, опасные расширения, symlink, подделку source ZIP и разрешённые/запрещённые пути Nginx.
