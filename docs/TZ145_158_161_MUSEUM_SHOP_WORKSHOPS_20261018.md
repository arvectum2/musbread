# TZ-145, TZ-158, TZ-161 — витрина без продажи и музейные мастер-классы

18.10.2026, закупка 0372200172326000015, п. 2.2.3.6.1. Работа через Mac mini, ArvectumSSD. По разрешению пользователя действующий сайт https://muzei-xleb.ru принят в качестве исходной рабочей редакции до корректировок заказчиком.

## Официальные данные — 12 мастер-классов

На действующем сайте https://muzei-xleb.ru/master-klassy опубликованы 12 уникальных программ: «Кувадка», «Веснянка», «Зерновушка-Благополучница», «Птичий двор», «Пасхальный заяц», «Рождественский Ангел», «Окно радости», «Конь-солнце», «Мельница-вертельница», «Солнце на радость», «Пасхальные украшения» и «Роспись изразца». Все 12 полных описаний скачаны напрямую через Mac mini с интервалом не менее 10 секунд. Один исходный мастер-класс расположен под /ekskursii/master-klass-melnica-vertelnica — исходный адрес сохранён.

По каждому источнику сохранены настоящие H1, URL, HTML, SHA-256, возрастное ограничение в тексте, дата снимка и URL изображения для аудита. Снимки находятся в apps/web/src/data/official-workshop-pages.json, скрипт воспроизведения — scripts/capture_official_workshops.py. Официальный каталог содержит минимальные возраста от 6+ до 10+. Отдельного официального каталога исключительно для взрослых там нет. 32 фотографии не скачаны и не перепубликованы: есть лишь URL-метаданные, до подтверждения прав.

На публичном сайте музея /magazin, /suveniry и /suvenirnaya-produkciya возвращают HTTP 404. 16 официальных ранее сохранённых информационных страниц не предоставляют достоверной номенклатуры сувениров. Упоминания исторических кондитерских магазинов в истории музея не считаем подтверждением наличия современных сувениров.

## Новая реализация

**TZ-161 — мастер-классы для детей.** /guide/children-workshops/ содержит 12 реальных раскрываемых карточек, возраст и полное описание из конкретного музея; ссылки на первоисточники. Нет выдуманных дат, мест, цен или фотографий. Контент редактируется из MoonShine.

**TZ-158 — мастер-классы для взрослых.** /guide/excursion-workshops-adults/ использует те же 12 исходных материалов, но честно предупреждает, что участие взрослой аудитории не подтверждено отдельным утверждённым перечнем музея. Возраст 6+ сам по себе не означает существование отдельной взрослой группы. При этом CMS-карточки не дублируются.

**TZ-145 — магазин без продажи.** /guide/museum-shop/ — действующая CMS-витрина информационных карточек опубликованных музейным редактором материалов. Нет корзины, формы заказа, платежей, checkout, списаний, регистрации или учётных записей покупателей. В отсутствие утверждённых товаров показывается сообщение «Каталог сувениров уточняется», телефон музея и ссылка на план визита. Ни одного выдуманного товара нет. Общая кнопка входного билета в шапке не относится к сувенирной витрине.

Использованы существующие MuseumEntry и MuseumSection без новых таблиц. Штатные opt-in команды:
- php artisan museum:import-official-workshops — только preview; --apply создаёт 12 source-backed страниц и две отдельные посадочные как private draft.
- php artisan museum:prepare-shop — только preview; --apply создаёт одну приватную вводную страницу витрины без товаров.

На production массовый импорт запрещён. При повторных запусках редакторский текст не затирается. Изменённый source SHA256 или чужой slug блокируют импорт.

Перед записью сохранена приватная полная копия SQLite .local_archive/db-backups/musbread-before-tz145-158-161-20261018.sqlite с целостностью PRAGMA integrity_check=ok. Итог: 63 приватных CMS черновика (плюс 15 за этот этап), 44 оригинальных документа без изменений. Продакшен сайта музея не менялся.

## QA

Python проверяет 12 отдельных URL и их SHA256, точное соответствие исходному каталогу, оригинальные возрасты и запрет публикации фотографий. PHP проверяет import preview, повторное применение, редакторский override, отсутствие ненастоящих товаров, отказ подмене источника/чужого slug/production bulk import. Playwright проверяет карточки, ограничения возраста, отсутствие продаж, доступные раскрывающиеся блоки и 320px.

Изолированный сквозной Laravel → JSON → Next.js прогон на временной копии SQLite тестово опубликовал 23 CMS записи, включая оба раздела мастер-классов, одну редакторскую правку и магазин. Только в одноразовой QA-базе добавлен ясно помеченный вымышленный товар для проверки карточки магазина. Этот товар не добавлялся в рабочую CMS и не копировался в Git. Проверено отсутствие в витрине корзины/форм, приоритет редакторского текста в обеих категориях, сохранение 11 закрытых индивидуальных черновиков мастер-классов, 44 музейных файлов по оригинальным SHA256.
