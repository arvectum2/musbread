## Технические исправления и проверки

**🟢 TZ-120 — поиск по всему сайту в шапке.** Десктоп уже имел GlobalSearch и кнопку «Найти», использующие единый индекс опубликованных страниц. На мобильных экранах поиск был спрятан в меню. В SiteHeader добавлена отдельная видимая клавиатурно доступная ссылка «Поиск», ведущая к существующему /search/, без второй системы поиска и сбора ПДн. Перестроена сетка шапки на ширинах до 630px. E2E: 1440/768/390/320 на главной, новостях и афише, отсутствие горизонтальной прокрутки, Enter по ссылке.

**🟢 TZ-173 — фиксированное горизонтальное мега-меню при прокрутке.** Playwright на четырёх маршрутах при ширине 1440px реально прокручивает страницу и проверяет, что шапка остаётся на верхней границе (CSS sticky). На мобильных меню преднамеренно становится раскрывающимся.

**🟢 TZ-174 — выпадающие подразделы.** Используется единое дерево разделов CMS и существующий компонент меню, на десктопе и мобильном — нативные details/summary, Enter открывает и приводит к нужной странице. Проверены видимость и маршруты.

**🟢 TZ-177 — строка поиска с автодополнением.** У существующего GlobalSearch доступные combobox/listbox, результат из опубликованного индекса, ArrowDown/Enter, правильная навигация. Тест использует реально существующий запрос «история» и проверяет выбранную ссылку. Результаты реального музейного корпуса подлежат отдельному редакционному UAT.

Все четыре технических требования отмечены зелёными по проверенному коду и браузерной регрессии. Приёмка окончательных названий разделов и реального содержания музеем пока не проводилась.

## TZ-238/240 — настоящий Browser Page Zoom (🟡)

До этого этапа существовали только 90 имитаций масштаба через CSS viewport, что **не эквивалентно** Page Zoom. Добавлен отдельный тест scripts/qa_native_chrome_zoom.mjs, использующий **настоящий API chrome.tabs.setZoom / getZoom** в Chrome for Testing / Playwright Chromium, запущенном с временным профилем и временным Manifest V3 расширением только для localhost.

Проверены: 6 опубликованных маршрутов × 3 начальные ширины (1440, 1024, 768 px) × 5 настоящих масштабов **100/125/150/175/200% = 90 измерений**. Отдельно подтверждаются значение browser tab zoom, изменение CSS viewport и devicePixelRatio, отсутствие горизонтального переполнения document/body и возврат профиля без изменения рабочего браузера пользователя. **90/90 PASS; максимальное положительное переполнение — 0 px.**

Подтверждённый результат **только Chrome for Testing (движок Chromium)**, а не официальный приёмочный протокол для всех браузеров. Существующий нативный Safari smoke через Apple Events на Mac mini не завершился (скрипт завис на управлении Safari, завершён только тестовый osascript и локальный тестовый сервер; Safari как приложение не прекращалась). Не проверены настоящий Page Zoom в Safari, Firefox, Edge, Яндекс Браузере, последние две версии каждого и окончательные музейные страницы/формы. Поэтому TZ-238 и TZ-240 остаются **🟡** без фиктивного повышения статуса.
