# TZ-129/130/131/134/137/141/142 — редакторский перенос музейных материалов

**Дата 17.10.2026.** Основание — закупка 0372200172326000015, приложение №3 ТЗ, п.2.2.3.6.1. Источник — публичный действующий музейный сайт https://muzei-xleb.ru, принят пользователем как исходная редакция; прямые HTTP-запросы выполнены с Mac mini.

## Архитектура по ТЗ, без ненужного усложнения

В проекте уже есть MoonShine, записи MuseumEntry, документы MuseumDocument, навигация MuseumSection и статический экспорт. Не создавали новых таблиц, CMS, хранилищ или сервиса синхронизации.

Добавлена одна явная команда: php artisan museum:import-official-pages. По умолчанию **только план** без сетевых запросов и изменения БД. С флагом --apply создаёт только отсутствующие записи типа page в статусе draft, привязывает к готовой музейной структуре, сохраняет дату/URL официального источника в excerpt. Уже существующие материалы, редакторские правки, статусы и вложения не изменяет. На production массовый --apply запрещён, работать можно через обычные действия редактора. Для таблиц официальных цен стандартный HTMLPurifier разрешает только безопасную таблицу, без JS и атрибутов событий.

С --apply --documents валидные локальные оригиналы привязываются в приватном Laravel storage. Проверяется URL и наличие ссылки непосредственно в HTML первоисточника, точные длина и SHA256, штатный MuseumDocumentInspector, формат и лимит 15 МиБ. Непрошедшие проверку файлы остаются только официальными ссылками из исходного HTML; лимит не обходится. Проверка доступности файлов не помечается выполненной.
