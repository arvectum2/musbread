# TZ-140/143/144 — посетителям, доступная среда, Пушкинская карта

18.10.2026. Источник — действующий официальный сайт https://muzei-xleb.ru. Основание — ТЗ закупки 0372200172326000015, п. 2.2.3.6.1. По прямому разрешению участника закупки действующие музейные публикации считаем рабочими исходными редакциями до корректировок заказчика.

## Что сделано

На /guide/plan-visit/ помимо адреса, графика, контактов и метро есть **конкретная информация для планирования доступного посещения** из исходной страницы /informaciya-dlya-mgn: шесть карточек об оборудованном входе, пандусах, подъёмнике, туалете первого этажа, экскурсиях с тактильными материалами и Брайлем, частичной доступности материалов для гостей с нарушениями слуха, собаке-проводнике. Показано предупреждение об отсутствии тактильной/визуальной информации на участке от метро. Даны реальный официальный источник, ссылка на подробную страницу и телефон музея для предварительной связи. Ни один пункт не объявляет маршрут полностью безбарьерным.

На /guide/accessible-museum/ по-прежнему виден полный исходный официальный музейный текст, теперь дополненный компактной практической сводкой и переходом к плану визита.

На /guide/pushkin-card/ размещён полный исходный текст музея о программе (14–22 года, онлайн-покупка именного билета и прямая ссылка на реального билетного оператора vmuzey.com), без выдуманных мероприятий.

## MoonShine и источники

Через действующую команду museum:import-official-pages с явным --apply добавлены две отдельные **приватные редакторские draft-страницы** из строго сверенных по SHA-256 действующих текстов /informaciya-dlya-mgn и /pushkinskaya-karta. Новых таблиц не создавалось, чужие правки не перезаписываются. Перед применением сделана резервная копия SQLite на ArvectumSSD: .local_archive/db-backups/musbread-before-visitor-source-import-20261018.sqlite. Итог локальной базы: 24 draft/44 приватных документа, никаких production-публикаций.

Происхождение всех коротких формулировок сводки проверяет tests/test_official_accessibility_visit.py; никаких неподтверждённых фотографий, мест на парковке или обещаний персональной помощи не добавлено. Четыре браузерных теста проверяют мобильный 320px, полный музейный текст, внешнюю ссылку билетов, клавиатурную читаемость и реальные сведения. Сквозной тест на одноразовой SQLite собирает девять опубликованных только для QA CMS-страниц и сверяет 44 файла по SHA-256; рабочая база остаётся закрытой.
