# Подлинные музейные PDF и DOCX: сохранение старых ссылок при смене DNS

**18.10.2026 — АКТУАЛЬНАЯ ГЛУБОКАЯ ПАРТИЯ:** по дополнительной source-locked [матрице из 24 подлинных ссылок](../seo/DEEP_DOCUMENT_ORIGINAL_SOURCE_URLS_20261018.csv) на Mac mini загружено **23 достоверных PDF/DOCX**. Одно недоступное место — исторический `/sites/default/files/page/202110271242-prikaz_no94.pdf` (исходный HTTP 404). Общий автономный локальный пакет — **82 исходных документа, 244,75 МиБ**, все байты SHA-256 проверены и разложены по старым URL; ни один оригинальный PDF/DOCX в Git не отправлен.

**18.10.2026 — АКТУАЛЬНЫЙ ОХВАТ:** к прежним 57 оригиналам добавлены 2 проверенных файла: PDF о посещении организованными группами и DOCX с информацией для дарителей. **59 PDF/DOCX, 208,46 МиБ**, побайтово сохранены по первоначальным URL. Архивный приказ №94 2021 года уже отдаёт HTTP 404 на самом музее, не подменён. Старые значения 57 ниже — история предшествующего этапа.

**18.10.2026, Mac mini / ArvectumSSD. Готова самостоятельная локальная сборка оригинальных документов.**

Сохранён **57 подлинных URL из действующего музея**, то есть **54 PDF и 3 DOCX, 208,07 МиБ**. Они подтверждены сохранёнными ранее манифестами из трёх закрытых музейных наборов: `.local_archive/official-site-originals/` (44 документа), `.local_archive/official-menu-originals/` (11 документов) и `.local_archive/science-originals/` (2 документа); одинаковые URL с одинаковой контрольной суммой учитываются один раз. [Машиночитаемый реестр](OFFICIAL_ORIGINAL_DOCUMENTS_DEPLOYMENT_20261018.json) хранит точные старые URL, размеры и SHA-256.

**Файлы реально скопированы** из закрытых оригиналов в локальную статическую сборку `apps/web/out/sites/default/files/…` по **тому же пути**, что и на исходном музее. При смене DNS браузер продолжает обращаться к старому пути, но документ уже обслуживается нашим сервером. Оригинальные байты сохранены без изменений: нет OCR, пересохранения, перекодирования или сжатия, SHA-256 и длина совпадают у всех 57 файлов. В исходные JSON и правовые тексты правок не вносилось.

## Повторяемая сборка

На **Mac mini с доступом к исходному архиву** (из репозитория `musbread`):

```bash
cd apps/web
npm run build:museum-deploy
cd ../..
.venv/bin/python scripts/export_official_museum_original_documents.py --verify-only
```

`build:museum-deploy` сначала запускает статический Next.js build, создаёт 239+ переходников старых страниц и актуальную Nginx-карту, затем копирует подлинные документы. **Обычный `npm run build` не содержит PDF/DOCX из закрытого архива**: это важно при сборке только из GitHub/GitVerse! Для окончательной публикации использовать именно архивную сборку с Mac mini, иначе исходные файлы по старым путям будут 404. Исходные 208 МиБ намеренно **не** добавлены в Git. На сервер/в хранилище выкладывается **весь** `apps/web/out`, включая фото, документы и статические страницы.

## Что проверено и что осталось

- Все 57 документов прошли проверку SHA-256 на входе и при копировании; формат проверен по сигнатурам `%PDF` и `PK` (DOCX).
- Unit-тест: `tests/test_museum_original_documents_static.py`; тест статических ссылок: `apps/web/e2e/museum-legacy-original-document-cutover.spec.ts`.
- На боевом веб-сервере отдельно проверить `Content-Type`, `Content-Disposition` и заголовки безопасности для больших PDF/DOCX, возможность скачивания файла и правила кэширования.
- Правила HTTP 301 для страниц и исторических JPG/thumbnail URL подготовлены, но **не включены на боевом сервере**: [Nginx-конфигурация](../../deploy/nginx/README.md). HTML-переходники в статической сборке работают самостоятельно.
- Набор охватывает проверенные 57 документов из исходных манифестов. Внешние URL к другим файлам, если встретятся дальше в глубоком архиве, требуют дополнительного источника и проверки, а не вымышленных файлов.
