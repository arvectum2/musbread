Источник — реальные фотографии на https://muzei-xleb.ru, адреса получены из проверенных музейных страниц экскурсий и мастер-классов.

- **Ноль** фотографий автоматически допускается к публичному экспорту: у всех признак source_rights_pending=true, исходные ссылки сохранены. Требуются отдельные правовые и редакторские согласования с музеем.

## Воспроизведение

Список источников и хешей: [OFFICIAL_PHOTOS_IMPORTED_20261018.csv](OFFICIAL_PHOTOS_IMPORTED_20261018.csv).
Приватные оригиналы и манифест — .local_archive/museum-official-photos/ на внешнем ArvectumSSD; эти файлы не добавляются в Git.
Скрипт прямого скачивания — scripts/cache_official_museum_photos.py (museum robots Crawl-delay 10 сек), проверка — scripts/audit_official_museum_photo_import.py.
Импорт — php artisan museum:import-official-photos --apply; без --apply запускается только безопасный dry-run.
