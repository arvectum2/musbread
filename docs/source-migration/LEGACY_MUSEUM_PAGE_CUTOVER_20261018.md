# Сохранение музейных URL после переключения домена: готовая карта маршрутов

**18.10.2026 — ПОСЛЕДНИЙ SEO-КОНТРОЛЬ:** [518 достоверных исходных музейных URL](../seo/URL_MIGRATION_MATRIX_20261018.csv): 448 самостоятельных страниц на первоначальных адресах и 70 подлинных Drupal `/node/N` с подготовленными, но не активными серверными 301. Больше **нет редиректов на якоря** (0). В старых текстах дополнительно нашли [82 ссылки вне текущей карты](../seo/ORIGINAL_MUSEUM_CROSSLINK_GAPS_20261018.csv) — следующий source-first обход. Документы (59) и фото-URL (269 → 264 WebP) автономны в локальной сборке. Прежние цифры ниже — история разработки, не свежие итоги.

> **18.10.2026 — УТОЧНЕНИЕ: SEO-стоп-гейт P0.** Эта карта — описание текущих **прототипных HTML-переходников**, а не утверждённая стратегия боевого переноса. Приоритет [CP-SEO-01](../SEO_MIGRATION_NO_REGRESSION_20261018.md): **сохранять старые URL с полным содержимым и HTTP 200** (например `/novosty/...`) вместо массовых `meta refresh` на `/news/...` либо каталоги с якорями. Для доказанно неизбежных исключений — адресный HTTP 301/308 на равноценную страницу. Выход в продакшн до проверки всех значимых URL и метрик **запрещён**.

**18.10.2026 — РЕЗУЛЬТАТ ПОСЛЕ SEO-ПЕРЕПРОВЕРКИ (актуальная редакция):** [493 исходных музейных пути](../seo/URL_MIGRATION_MATRIX_20261018.csv) имеют рабочие локальные назначения; **356 возвращают полноценный исходный HTML напрямую** (280 новостей и 76 выставок). Из 137 прочих статических HTML-переходников 60 относятся к реально существующим историческим `/node/N` (в боевой карте предлагается один 301 к человекочитаемой выставке), остальные 77 — старые меню/программы/каталоги. Из оставшихся 137 переходников 40 идут к якорям общих разделов: **SEO-гейт NO-GO**. [Подробный автоматический аудит](../seo/CP_SEO_01_FIRST_POST_MIGRATION_AUDIT_20261018.md) и [879 предложенных, не применённых 301](../../deploy/nginx/README.md), включая 462 источника изображений. Оригинальные старые URL новостей и выставок больше **не должны переадресовываться**.

**18.10.2026.** Подготовлено 279 статических обратных совместимых адресов действующего музея. [Полный CSV с точными целями](LEGACY_MUSEUM_PAGE_ALIASES_20261018.csv). Данный режим нужен, чтобы музейное меню, старые ссылки на новости и карточки экспозиции продолжали работать после перевода `muzei-xleb.ru` на Next.js.

- 170 настоящих адресов `/novosty/YYYY-MM-DD/...` направляются на **соответствующую самостоятельную страницу** `/news/museum-news-.../`; не на абстрактный индекс новостей.
- 32 адреса реальных выставок, 17 экскурсий, 12 мастер-классов, 11 залов — на существующие каталожные страницы **с точным якорем оригинального объекта**, не на произвольные несуществующие разделы.
- 33 уникальных оригинальных адреса музейного меню и прочие проверенные разделы — на существующие общие разделы сайта; повторяющиеся исходные адреса меню имеют один предсказуемый пункт назначения.
- Каждый `npm run build` запускает `postbuild`, который генерирует миниатюрные HTML-переходники `/old-path/index.html` непосредственно в статическую поставку `apps/web/out/` и проверяет существование целевых файлов **и якорей**.
- В статическом сборочном тесте: **279/279 целей существуют, 0 недостающих, 0 коллизий/петель**. В браузере проверены реальные старые адреса статьи 2025 года, страницы выставки, истории здания и раздела доступной среды, включая проверку конкретной карточки.

**Важно про тип редиректа:** текущие переходники — браузерные `<meta http-equiv="refresh">`, то есть они работают и на простом файловом сервере. Они **не дают настоящий HTTP 301**. При размещении на выбранном продакшн-сервере нужно использовать CSV как точную спецификацию для HTTP 301/308 или штатных правил переадресации хостинга. Не использовать автоматическое правило «старый `muzei-xleb.ru` → `muzei-xleb.ru`»: оно создаст петлю.

**Важно про старые абсолютные адреса изображений:** 233 музейных фото-URL уже сопоставлены с **229 WebP-файлами нового сайта** (`/media/museum-source/...`). Наш сайт не загружает фото с прежнего Drupal. Для внешних сохранённых JPG/thumbnail URL подготовлена, но не применена [Nginx-карта HTTP 301](../../deploy/nginx/README.md) — в общей карте **715 точных правил** по проверенным страницам и изображениям; не перенаправляет сайт на себя. Данный отчёт подтверждает автономность **страниц сайта и их внутренних фотозагрузок**, а не бесконечную обратную совместимость всех URL из интернета.

Существующие 57 официальных оригинальных PDF/DOCX уже проверены по SHA-256 и **побайтово скопированы в локальную полную статическую сборку по старым URL**; для публикации нужна специальная команда `npm run build:museum-deploy` на Mac mini ([протокол](ORIGINAL_DOCUMENT_DOMAIN_CUTOVER_20261018.md)). Не повторять OCR: байтовые оригиналы уже скачаны. Фактическую настройку боевого HTTP-сервера нельзя считать выполненной до выбора хостинга и подписания договора.
