**Проверено 19.10.2026 на Mac mini, ArvectumSSD; без взаимодействия с продуктивным сервером музея.**

## Что исправлено

1. В `apps/web/package.json` устаревший `npm run build:museum-deploy` копировал оригинальные документы и 27 новостных индексов, **но пропускал фотоархив**. Теперь эта команда ссылается на один защищённый сборщик `scripts/build_complete_museum_static_release.py --build` в проектном venv. Добавлен `npm run verify:museum-deploy` для проверки без пересборки.
2. Добавлен `scripts/audit_museum_static_internal_links.py`. Все локальные ссылки/ресурсы из каждого HTML проверяются против файлов именно собранного комплекта. Любой **новый** неразрешённый внутренний URL останавливает выпуск. Исторические неисправности исходного музея **не объявляются зелёными**: они перечислены по точным адресам и подсчитываются отдельно.
3. Аудит встроен в финальную проверку защищённой сборки, добавлены 4 самостоятельных регрессионных теста (включая отказ на новых 404). Продуктивный DNS, SSL, сервер музея, реальный robots.txt и Яндекс/Google не изменены.
