# CP-SEO-05 · реальный robots.txt и стандартная sitemap действующего музея · 18.10.2026

**Только наблюдения через Mac mini. Живой сайт/DNS не меняли. SEO-релиз NO-GO.**

18 октября 2026 года напрямую проверены две рабочие версии домена музея: `https://muzei-xleb.ru` и `https://www.muzei-xleb.ru`.

| URL первоисточника | HTTP | Проверенное содержание |
|---|---:|---|
| `https://muzei-xleb.ru/robots.txt` | 200 | Старый Drupal `robots.txt`, SHA-256 `278e83bc…a9b762` |
| `https://www.muzei-xleb.ru/robots.txt` | 200 | **Побайтово идентичен** варианту без `www` |
| `https://muzei-xleb.ru/sitemap.xml` | 404 | НЕТ XML на стандартном пути; сервер отдал HTML 404 |
| `https://www.muzei-xleb.ru/sitemap.xml` | 404 | НЕТ XML на стандартном пути; сервер отдал HTML 404 |

Все четыре HTTP-результата, точные SHA-256, размер и исходные байты сохранены **приватно** на Mac mini в `.local_archive/seo-old-site-indexation/`. Исходный `robots.txt` содержит `Crawl-delay: 10`, запрещает индексацию служебных папок Drupal (`/admin/`, `/user/`, `/search/`, `/node/add/` и др.), **но не запрещает основной музейный контент**. Ни у одного из старых `robots.txt` нет директивы `Sitemap:`. Это **не доказательство отсутствия других XML/HTML-карт** по нестандартным URL и не подтверждение количества реально проиндексированных страниц: метрики следует получать из Яндекс Вебмастера и Google Search Console.

## Что учтено в новом проекте

1. Тестовый сайт (до договора, до проверки старого поискового индекса) по-прежнему **`User-Agent: *` / `Disallow: /`**, `noindex` и пустая XML-карта. Никаких изменений старой поисковой индексации нет.
2. Будущий режим на подтверждённом домене (`MUSBREAD_SITE_APPROVED=true` **и** `MUSBREAD_RELEASE_HOST=muzei-xleb.ru`) повторяет **ограничение `Crawl-delay: 10`**, исключает старые Drupal `/admin/`, `/user/`, `/search/`, `/node/add/` и приватные области нового CMS (`/cms/`, `/moonshine/`). Это не команда на включение, а подготовленные проверки на будущее.
3. При согласованном выпуске новая XML-карта будет создана заново **только из 467 подтверждённых отдельных музейных URL**. 88 исторических `/node/N` и 27 старых `?page=N` не добавляются как конкурирующие canonical; у всех архивных списков canonical `/novosty`, как у Drupal. Непроверенная главная страница/демонстрационные CMS-разделы/устаревшая афиша не должны автоматически попасть в sitemap.
4. Для `www`/без `www` нужно отдельно получить от музея поисковый baseline и договориться о каноническом домене: **оба исходных сайта пока HTTP 200/self-canonical**. Не вводить новый redirect без этих данных.

**Результат:** сохранены исходные правила и устранена опасность заменить старые архивные query-страницы одной и той же выдачей. До проверки live Nginx 301/200 для 555 pathname + 27 query URL, реального robots/sitemap на одобренной площадке, SSL, состояния Яндекс/Google и отката — **NO-GO**.
