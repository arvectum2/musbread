# CP-SEO-03 · безопасность доменов, canonical и sitemap · 18.10.2026

**Статус: NO-GO.** Все проверки выполнялись на Mac mini в локальном проекте. Живой сайт музея и DNS не изменены. Сборка предконтрактного сайта по-прежнему имеет `noindex, nofollow`, `robots.txt: Disallow: /`, нулевой sitemap. Не путать готовность офлайн-кода с подтверждённой возможностью запуска.

## Проверенные в исходном музее хосты

18 октября 2026 года оба действующих хоста отвечали самостоятельным HTTP 200 и объявляли **свои собственные canonical** в HTTP `Link`:

| Проверенный оригинальный хост | Фактический код | Объявленный первоисточником canonical |
|---|---|---|
| `https://muzei-xleb.ru/` | HTTP 200 | `https://muzei-xleb.ru/` |
| `https://www.muzei-xleb.ru/` | HTTP 200 | `https://www.muzei-xleb.ru/` |

Доказательство HTTP HEAD сохранено приватно на Mac mini: `.local_archive/seo-host-check/dual-host-source-20261018.txt`. **Не делать редирект www → без www до анализа Яндекс Вебмастера/GSC и согласования.** Пока непонятно, насколько каждый хост индексирован и получает органические ссылки. Нельзя объявлять один из них неиспользуемым без данных.

## Реализованный технический защитный контур

- **467 из 555 исторических адресов** возвращают собственный исходный HTML, `200` в статической локальной проверке, с ровно одним canonical, равным исходному URL включая отсутствие завершающего `/`. Каждая страница в прототипе `noindex`.
- **88 адресов Drupal `/node/N`** — подтверждённые переходы к настоящим самостоятельным музеям статьям; ожидают одношаговых боевых HTTP 301.
- **881 правило** в Nginx-карте (`368` к статическим страницам, `513` к собственным WebP); [офлайн-аудит графа](NGINX_301_GRAPH_PREFLIGHT_20261018.md) проверил 0 цепочек, 0 циклов, 0 отсутствующих целевых статических файлов. **Это не замена живому `nginx -t` и тесту HTTP-ответов.**
- **310 старых музейных адресов изображений → 303 локальных WebP**; **101 оригинальный PDF/DOCX (287,96 МиБ)** доступны по старому пути. Последний [аудит оригинальных ссылок](ORIGINAL_MUSEUM_CROSSLINK_GAPS_20261018.csv) нашёл только три уже недоступных ресурса: два исходных 403 (`/node/462`, `/obratnaya-svyaz`), один исходный 404 (приказ №94 за 2021 год). В этой обнаруженной последовательности отсутствуют другие известные пропуски. Это не гарантия полного охвата неизвестных поисковикам страниц.
- Два **независимых** разрешения требуются для публичной индексации: `MUSBREAD_SITE_APPROVED=true` и `MUSBREAD_RELEASE_HOST=muzei-xleb.ru`. По умолчанию оба не заданы; одного флага недостаточно.
- Даже после обоих флагов метаданные тестовых CMS-разделов, английских черновиков и домашней страницы **остаются noindex**. Отдельным явным разрешением могут индексироваться только подтверждённые исторические URL. Генератор sitemap включает только **467** оригинальных адресов, без демонстрационных записей, неподтверждённых событий, технических `/guide` и `/news`-дублей и без 88 редиректов. Домашняя страница отдельно не внесена до приёмки дизайна и контента.

## Что запрещает переключение домена

1. Отсутствует решение заказчика о первичном домене и судьбе отдельного `www` с самоканоникализацией. Нужны отчёты по обоим хостам.
2. Не получены базовые данные из Яндекс Вебмастера и Google Search Console: проиндексированные URL, 28/90-дневные клики, показы, CTR, позиции и топовые входные страницы обоих хостов. Отдельно нужна Метрика / GA4, текущие редиректы и связанные цели.
3. Нет подтверждённой боевой площадки/Nginx, SSL, настроек обработки URL без слеша, правил старой пагинации `/novosty?page=N`, живого HTTP-301 smoke-test для 881 правил, проверки всех 101 документов и 303 WebP. На Mac mini `nginx` отсутствует из PATH; установка боевого сервера не проводилась.
4. Не согласованы дизайн, содержание homepage, исходные правовые тексты, технические условия CMS, резервная копия и план отката. Неизвестные поисковые landing pages тоже потребуют сверки.
5. Три ошибки на исходном музее не замаскированы пустышками; по ним нужен запрос заказчику при необходимости.
