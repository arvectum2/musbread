## Критические проблемы, найденные после переноса

1. **P0: ещё 88 исторических `/node/N` имеют запасной `meta refresh` только на тестовом статическом стенде.** На настоящем хостинге они должны отвечать одной проверенной HTTP 301 прямо на сохранившийся человекочитаемый URL; предложенные правила ещё не активированы. Это пригодно для доконтрактного просмотра, **не** для безопасной замены Drupal и сохранения выдачи. Переход на 301 с нового URL к якорю общего каталога тоже недостаточен для важных индексируемых страниц.
2. **P0: 0 переходов на якоря.** В первую очередь нужно сохранить существующие отдельные старые URL с исходным H1, body и метаданными (`200 OK`); `/news/…` и другие технические пути оформить дублями с `301` к исходным, если они останутся нужны. Для `/node/N`, которые действительно были HTTP-переходами музея, сделать только проверенную точечную 301-карту на старый человекочитаемый URL без цепочек.
3. **P0: 0 эффективных целевых HTML без явного canonical, 0 отличаются H1/title от заголовка исходной публикации.** Они не обязательно означают потерю контента (например, выставка содержится в карточке), но это **неэквивалентность для индексации**.
4. **P0: режим разрешения индексации пока привязан к демонстрационному домену `musbread.ru`, не `muzei-xleb.ru`.** Запускать `MUSBREAD_SITE_APPROVED=true` как готовую миграцию нельзя: `musbread.ru` и неподтверждённые URL уже исключены из защищённой генерации; до отдельного разрешения index всё равно запрещён и нельзя развертывать на действующем домене. Не копировать демонстрационные `/events` как актуальную афишу.
5. **Внешние дефекты первоисточника:** PDF-приказ №94 от 27.10.2021 уже отдаёт 404 на действующем музее; `/node/462` (архивный адрес афиши) отдаёт 403. Нужно документировать и согласовать исправление по существу; не добавлять пустышки.
6. **До доступа к исходным кабинетам заказчика** неизвестны топовые входные страницы, действительные canonical из поисковой выдачи, индекс/показы/CTR, Метрика, коды подтверждения; точную потерю/рост органики нельзя оценить. Сохранение домена само по себе не гарантирует сохранения позиций.
