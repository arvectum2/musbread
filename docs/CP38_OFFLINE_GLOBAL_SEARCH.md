# CP-38D — полнотекстовый поиск по опубликованной статике

Дата: 16 октября 2026. Доконтрактный прототип Музея хлеба, №0372200172326000015. CP-38D **не контрактный** CP-38 (приёмочные испытания).

## Изменение

- Существующее поле GlobalSearch в шапке и на странице `/search/` сохранено. Подсказки содержат максимум 8 релевантных ссылок; на странице поиска теперь доступна кнопка **«Показать все результаты»**, раскрывающая полный перечень совпадений с названием, разделом, анонсом и реальной ссылкой.
- Индексируются действующие навигационные каркасы, события и материалы из **публичного** `published.json`, включая содержимое поля `body`. Статические страницы `/guide/` охвачены по заголовкам/описаниям, не по отсутствующим музейным текстам; документы охвачены по метаданным/контенту CMS, но бинарные PDF/DOCX/XLSX пока не индексируются.
- Поиск нормализует регистр, `ё/е`, знаки пунктуации и пробелы; для многословного запроса требуются **все** слова, даже находящиеся в разных полях. Точное совпадение с названием получает приоритет, затем упоминания в категориях/анонсах, затем в основном тексте. Вывод стабилен и не дублирует URL.
- HTML из ранее опубликованных материалов преобразуется **только в текст для индекса**. В результате ссылки/анонсы выводятся React с экранированием. Динамический сервер, сторонние поисковые сервисы, CMS API, cookies посетителя, новые платные лицензии не нужны.
- Навигация подсказок по ArrowDown/ArrowUp/Enter/Escape осталась. На мобильном поиск доступен через меню. При раскрытии полного списка выпадающие подсказки скрываются.

## Доказательства

- `apps/web/src/data/search-core.test.ts`: нормализация русского текста и HTML-сущностей, полнотекстовые и многословные совпадения, стабильная сортировка, отсутствие дублей.
- `apps/web/e2e/global-search.spec.ts`: браузерное нахождение текста только из тела опубликованной новости, полный список результатов, переход с клавиатуры и отсутствие запросов к закрытой CMS.
- Выполнять `npm run test:search`, `npm run lint`, `npm run build`, `npm run test:e2e`; шаг `test:search` подключён в GitHub Actions.

## Чего пока нет

- Бинарные документы не преобразуются в поисковый текст (ограничения безопасного контура, OCR/лицензий, прав на музейный архив). Никаких документов или персональных данных музея в репозиторий не добавлено.
- Это простой клиентский индекс, не полноценный поисковый движок с морфологией русского языка, настройкой фильтров или серверным ранжированием.
- При увеличении реального корпуса после контракта потребуется оценить производительность и качество выдачи с сотрудниками/посетителями музея; эти испытания ещё не проводились.
- Публичный индекс **по контракту экспорта не содержит черновики и отложенные записи**. Для проверки сохранённых черновиков используется только закрытый предпросмотр CP-37D.
- TinyMCE и его текущий режим не изменялись. Вопросы лицензирования перед передачей остаются открытыми.
