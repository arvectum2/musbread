**CP-SEO-04, 18.10.2026:** [27 source-locked старых query-страниц архива `/novosty?page=1..27`](seo/ORIGINAL_MUSEUM_NEWS_PAGINATION_PRESERVATION_20261018.md) были отдельной SEO-опасностью, не попадающей в матрицу 555 pathname URL. [881 офлайн-валидных правил 301](seo/NGINX_301_GRAPH_PREFLIGHT_20261018.md), но **никакого реального Nginx/HTTP и DNS изменения пока нет**. **Релиз NO-GO**.

**18.10.2026 — новое подтверждение исходных файлов:** в полном локальном статическом пакете уже **82 истинных PDF/DOCX (244,75 МиБ)**, включая 23 дополнительно скачанных с юридических страниц. Единственный недоступный старый приказ №94 (404) не подменён. Новая матрица внутренних ссылок содержит **59 открытых URL**: 21 страница, 37 изображений и этот 1 исторический PDF. Боевая SEO-готовность всё ещё **NO-GO**.

**Решение владельца проекта от 18.10.2026.** Перевод `muzei-xleb.ru` на новую архитектуру (Laravel/MoonShine в закрытом контуре + статический Next.js на публичном) **не должен создавать предотвратимые потери уже достигнутой поисковой видимости, органического трафика, ссылочного веса, доступности контента и данных аналитики музея**. Сохранить домен **недостаточно**: главное — сохранить рабочие канонические URL, содержимое, метаданные и доступность. Нулевых колебаний позиций гарантировать нельзя, но не допускать неконтролируемых изменений.

**Приоритет:** P0, выше косметической унификации адресов и удобства новой маршрутизации. **Гейт:** NOW для аудита/подготовки; CUSTOMER для метрик, согласования спорных URL и продакшн-проверки; RELEASE только после доказанного прохождения критериев. Это дополнительное эксплуатационное обязательство по безопасной миграции, **не выдавать за новый пункт исходного ТЗ и не менять арифметику 325 требований**.

## 1. Неподлежащие нарушению правила

1. **Сохранить внешние URL как есть.** Для каждой существующей значимой страницы исходный `scheme + host + path` (включая транслитерацию, регистр, окончание `/`, дату и slug) должен отвечать `200 OK` и показывать **соответствующий полный материал** на новом сайте. Замена `/novosty` на `/news` сама по себе не нужна; фронтенд может использовать любой внутренний компонент/модель. Сохранить смысловые заголовки, H1, title, description, текст и перелинковку с улучшениями только там, где они обоснованы.
2. **Ссылки на документы и медиа — тоже контракт совместимости.** Сохранить оригинальные пути `/sites/default/files/...` и иные обнаруженные публичные ссылки, включая PDF/DOCX, изображения и файловые URL, так чтобы они не зависели от старого Drupal-хостинга. При невозможности отдать байты по старому пути — адресный серверный `301` на **тот же конкретный файл**, с проверкой доступности/Content-Type. Не подменять документы индексными страницами, не использовать внешние музейные URL как источник после переключения DNS.
3. **Если URL менять необходимо, только согласованная 1:1-карта.** Постоянный HTTP `301/308` со старого адреса на эквивалентный новый, без цепочек, циклов, редиректов на общие разделы и редиректов к якорю вместо отдельной индексируемой статьи. Коды `404/410` для реально удалённого контента — лишь после документированного решения. Не применять JavaScript и `meta refresh` как боевую замену HTTP-редиректа.
4. **Не создавать дублей.** Если одновременно доступны `/news/...` и `/novosty/...`, один адрес назначить каноническим (по умолчанию исходный музейный) и направлять альтернативу `301` на него; `rel=canonical` согласовать с реальным маршрутом и sitemap. Внутренние ссылки, меню, хлебные крошки и sitemap указывают на канонический адрес.
5. **`robots.txt` не сохранять побайтово:** действующий файл содержит Drupal-правила (`/modules/`, `/themes/`, `/node/` и др.). Разработать правила под новую архитектуру, сохранив доступ поисковиков к разрешённым публичным страницам и медиа, а приватные/CMS/служебные пути закрыть. Перед публикацией удалить случайный глобальный `Disallow`, `noindex`, неверный X-Robots-Tag, запреты CSS/JS. `sitemap.xml` должен возвращать 200 XML со всеми актуальными индексируемыми каноническими URL, без черновиков и дублей; при наличии другой исторической карты учесть её.
6. **Не рвать измерения и права в поисковых кабинетах.** Сохранять подтверждение владения Яндекс Вебмастер / Google Search Console, код/идентификаторы Метрики/GA4, согласованные цели и события, настройки consent/ПДн и интеграции; изменения — лишь с согласованием музея. Не запускать одновременно смену домена, массовое переименование URL и реорганизацию контента.

## Фактический результат после переноса 18.10.2026

Проверены 259 музейных источников фотографий → 255 собственных WebP, все 57 доступных оригинальных PDF/DOCX по сохранённым путям. Реально проверены 61 старый Drupal `/node/N` (60 редиректов музея на существующие выставки, один HTTP 403), один исторический PDF имеет уже на старом сайте HTTP 404. **До DNS — NO-GO**.
