## Приём обращений — отдельный открытый гейт

- В исходниках есть отключённые по умолчанию защищённый PHP sodium/SQLite ingress, Laravel mTLS-poller/import, read-only MoonShine inbox и opt-in форма Next.js ([описание](../services/request-ingress/README.md), [ADR](decisions/ADR_20261029_PUBLIC_INTERACTIONS_WITH_STATIC_EXPORT.md)). **Код ≠ развёртывание ≠ завершённый пункт ТЗ**.
- Текущий проект приёмщика предполагает **третий изолированный DMZ-хост**; музей сейчас закупает **только две ВМ**. Не требовать третью ВМ и не размещать PHP на публичном статическом хосте без отдельного технического согласования и решения об эксплуатационной ответственности. Обязательная функция обратной связи остаётся задачей исполнения контракта; её нельзя автоматически объявлять платным дополнением.
- До согласования: mailto-формы не обещают серверную регистрацию. Для боевого HTTP-приёма необходимы согласованный регламент ПДн и хранения/удаления, сеть, сертификаты/mTLS, backup/restore, негативные тесты и UAT. Не обрабатывать реальные обращения на временном Mac mini/VPS.
