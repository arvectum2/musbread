## TZ-308 — визуальное управление материалами: технически готово

MoonShine: визуальный TinyMCE на русском, абзацы, H2/H3, выделение, списки, ссылки, undo/redo, роли и даты публикации. Независимая браузерная проверка создала новость без программирования, изменила через визуальную форму и провела через SQLite, экспорт и статический HTML Next.js.

## TZ-309 — редактирование HTML: технически готово

В ту же панель TinyMCE 7.2.1 добавлен уже установленный локальный плагин «Исходный код» (code), без CDN. Браузерный тест из обычного визуального редактора открывает исходник, вносит P/STRONG/H2/OL/LI/a, возвращается к WYSIWYG, сохраняет и проверяет готовый статический HTML. Отдельный негативный PHP-тест проверяет удаление script/iframe/onclick/javascript: из исходного HTML серверным HTMLPurifier. Аварийный html-source режим сохранён, но не подменяет визуальный.

Риск: локальный runtime TinyMCE имеет лицензию GPL-2.0-or-later, хотя MoonShine PHP wrapper — MIT. Новая кнопка НЕ закрывает обязанности по лицензии или требования передачи исключительных прав. Перед сдачей необходимо юридическое решение о GPL или замена, проверка прав на все поставляемые библиотеки, обучение сотрудников и реальная редакторская UAT. См. docs/THIRD_PARTY.md и docs/CP34_SBOM_EDITOR_REPLACEMENT.md. Зелёный статус относится только к техническим функциям.

## TZ-295 — применимость норм зависит от функций ТЗ: частично

В существующем audit_legal_readiness.py добавлена единая восьмистрочная матрица: публикации действуют; формы обращений, собственные бронирования, аналитика и собственные рекламные интеграции выключены в прототипе; статус СМИ, федеральной ГИС и оператора связи не определяется по коду. У всех функций applicable_approved=false. При изменении настроек форм/аналитики негативный тест проверяет изменение технического статуса без вымышленного юридического одобрения. Нельзя вывести неприменимость закона к самому музею из отсутствия функции публичного сайта.

Действующий реестр: 17 нормативных пунктов, 12 раскрытий, 0 подтверждённых юридически. Музей должен подтвердить реально вводимые функции, правовую применимость и инфраструктуру. TZ-295 только частично.

Контроль: php artisan test, python unittest, реальный browser QA MoonShine 8/8, lint/build публичного Next и полный Playwright. Светофор после этапа: 37 готово, 111 частично, 177 не готово (325); в очереди без внешних блокеров 5, с зависимостями 283.
