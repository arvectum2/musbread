## 1. Действующий Музей хлеба — первоисточник

Через прямой доступ Mac mini проверены адреса и HTML:
- https://muzei-xleb.ru/novosty — HTTP 200, официальный раздел «Новости». Альтернативный адрес /novosti тоже отвечает 200; в новом справочнике только /novosty, чтобы не плодить два равноправных источника.
- https://muzei-xleb.ru/kontakty — HTTP 200, опубликованы служебные контакты и режим.
- https://muzei-xleb.ru/posetitelyam — HTTP 200, официальный раздел посетителя.
- https://muzei-xleb.ru/ — HTTP 200.

В существующей разработке уже были маршрут событий /events/, тестовая лента /news/, подтверждённый справочник контактов /guide/museum-contacts/, группы меню и дерево MoonShine. Новые юридические документы, программа мероприятий, цены и тексты НЕ создавались.

## 2. Сравнение музеев Санкт-Петербурга

Открыты сайты Государственного музея истории Санкт-Петербурга (https://www.spbmuseum.ru/) и Русского музея (https://rusmuseum.ru/). При сравнении ориентировались на понятные посетителю входные точки информации, новостей и посещения. Никакие разделы, тексты, правила, сотруднические данные и визуальная идентичность этих музеев не копировались. Структура действующего Музея хлеба и его ТЗ приоритетнее сравнительных примеров.

## 3. Исполненные изменения

1. Один каталог афиши: пункт «Все события» из исходного и CMS-дерева ведёт в уже существующий /events/. Старую прямую страницу-посредник не удаляли: она содержит ссылку на афишу.
2. На /news/ и /events/ доступен официальный источник музея /novosty. Тестовые записи продолжат быть обозначены как тестовые, без притворства, что это реальная афиша.
3. Добавлены прямые ссылки «Контакты» (основное + мобильное меню), «Спланировать визит» (подвал); удалён второй идентичный URL политики конфиденциальности.
4. У навигационных страниц различаются три типа контента: есть официальный первоисточник, новый раздел ТЗ без контента, и общий проект навигации.
5. В data/museum-reference.ts используется один метод guideHref для пункта афиши. Ранее существующие пути и материалы сохранены.
