## Безусловные блокеры выпуска

1. Две ВМ музея не представлены для проверки mTLS, отдельных IP, закрытого административного контура, ACL, резервного восстановления и публикации ≤60 минут.
2. Приём POST-обращений и заявки на экскурсию в CMS не проверены на боевой сети; согласия/оператор ПДн, роли и сроки хранения не утверждены.
3. Тестовая единая CSP размером ~227 КБ превышает консервативный лимит заголовка 8 KiB; обязательный live preflight теперь отклоняет такую CSP. До производства требуется строгая per-route CSP, проверка через реальный HTTP и запрет опасных ослаблений.
4. Шесть блокеров по юридической проверке лицензий и передаче исключительных прав открыты; технические SHA и GitHub не заменяют юридические документы.
5. Публичный CI проверяет только доступную ему часть материалов: исходники и некоторые архивные E2E недоступны на `checkout`. Не заменять реальные фото/PDF заглушками и не объявлять все CI проверки успешными.
