- [x] Выделены отдельно 11 печатных вариантов афиш, 4 афиши VK по рубрикам, 16 сочетаний 8 типов слайдов × 2 соотношения экрана и 9 сувенирных визуализаций.

- [x] Статусы для каждого результата — по умолчанию MISSING_CUSTOMER_APPROVED_RESULT. **Все 113 пока без утверждённого результата**. Это честная целевая спецификация, не фиктивные готовые дизайн-исходники.
- [x] Отдельный реестр docs/handoff/DESIGN_EVIDENCE.csv для будущих файлов, только безопасные относительные пути внутри репозитория. Никакие реальные секреты/заказные исходники туда без разрешения не добавлять.
- [x] Проверка правдоподобия реального формата по сигнатурам (в том числе векторных, растровых и презентационных), не по имени файла. **Даже прохождение сигнатуры не равно редактируемости или утверждению.**
- [x] scripts/audit_design_delivery.py --check --verify-generated блокирует повреждённые ссылки на ТЗ, исчезновение обязательного варианта, устаревший сводный отчёт и неподходящие «исходники».

- [x] Конкретный русский запрос на интервью: docs/handoff/CUSTOMER_INTERVIEW_DESIGN_CHECKLIST.md; машинный полный список входных материалов: CUSTOMER_INPUTS_AFTER_INTERVIEW.md.

- [x] Контроль и JSON-артефакт включены в GitHub Actions. Бюджет 0 ₽, Docker не используется.

## Что объективно ещё нельзя считать исполненным

- [ ] Три **содержательно разработанные и согласованные** концепции по 5+ страниц, с реальным стилем.
- [ ] Обязательные AI/EPS/SVG, PSD/TIFF 300 dpi при фактических печатных размерах, PPT/PPTX открываемые и редактируемые в согласованном ПО.
- [ ] Отобранный по интервью стиль, письменные согласования, проверенные лицензии шрифтов, копирайтинг/оригинальность, юридическая пригодность к регистрации.
- [ ] Реальный комплект печатных, музейных и сувенирных носителей с утверждёнными текстами и размерами.
- [ ] Подтверждённый получатель, внешний HDD и закрытый Яндекс.Диск, бумажный экземпляр, реальные контрольные суммы после копирования.
- [ ] Передача исключительных прав по исходному акту приложения 1 в двух подлинных экземплярах, согласование контракта и подписанные акты.
- [ ] Доказательства технического UAT музея, финальной доступности и клиентских материалов.

**Ограничение:** каталог из 113 позиций — инженерная детализация исходных требований, а не буквальное число, названное в ТЗ. Например, 8 типов слайдов сконструированы как один минимальный вариант покрытия — его необходимо согласовать с заказчиком, поскольку ТЗ не перечисляет все типы отдельно. Исходные номера TZ дают проследить формулировки.

## Команды

Из корня проекта:

    python3 scripts/audit_design_delivery.py --check --verify-generated --csv docs/handoff/DESIGN_DELIVERABLES.csv --markdown docs/handoff/DESIGN_DELIVERABLES.md --requests docs/handoff/CUSTOMER_INPUTS_AFTER_INTERVIEW.md --json /tmp/musbread-design-handoff.json
    python3 scripts/audit_delivery_readiness.py --require-complete-drafts
    python3 -m unittest tests.test_audit_design_delivery -v

Для обновления отчётов при изменении целей следует убрать только флаг --verify-generated и повторно проверить diff/TЗ; никогда не превращать наличие файла в утверждение прав или приёмки.
