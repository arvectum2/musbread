# MusBread: медиатека, публикация и безопасность

## Технология

- Приватная страница Laravel /admin/museum-media защищена аутентификацией MoonShine.
- Форма с нативным input type=file, drag-and-drop, обязательным alt и привязкой к MuseumEntry.
- Проверка: содержимое изображения, MIME JPEG/PNG/WebP, максимум 5 МБ, максимум 4096 px по стороне и 16 Мп.
- GD декодирует изображение, перекодирует в WebP (качество 82), удаляет имя оригинала, EXIF, метаданные, другие форматы. Сохраняемое имя — случайный UUID.
- Исходная картинка доступна только по защищённому preview URL. Публичный symlink Laravel storage не используется.
- Каждое создание/обновление/удаление регистрируется в закрытом audit (ID актёра и названия изменённых полей).
- Изображения отображаются на Next.js только после публикации привязанного материала. Статические HTML и WebP пересобираются в отдельном, внешнем публичном контуре.
- SHA-256 + длина каждого public/media/*.webp фиксируются в snapshot-manifest.json. Изменение файла блокирует релиз.
- Если материал возвращён в статус draft, его фото удаляется из следующей публичной сборки. Предыдущие неизменяемые версии доступны только закрытому оператору для восстановления.
- Без третьих сторон, облачных фотографий, платных API, настоящих клиентских данных или публичного доступа к CMS.

## Проверки

PHP feature tests: гостевой запрет, Editor+Admin auth, обработка WebP, удаление метаданных и пути оригинала, обязательный alt, недопустимый SVG, ограничения пикселей, изменение подписи/привязки, публикация только approved content, отзыв картинки, отказ при подмене.
Python unit tests: отсутствие файла и несовпадение контрольной суммы прерывают релиз.
Next.js: responsive media gallery, Image alt/caption, только статическое содержимое.
Автоматический Playwright Chromium с одноразовой QA-учётной записью проверяет реальную загрузку через UI; ручная проверка Safari/Chromium-GOST остаётся отдельным пунктом.

## Осталось до сдачи

Пакетная загрузка, удобная сортировка галереи, редактирование изображения (кадрирование), обложка события, доступность для скринридеров, автоочистка осиротевших приватных файлов при каскадном удалении материала, отдельные политики резервного копирования. Эти пункты требуют согласования с заказчиком или самостоятельной доработки.
