# CP-31D — указатели, музейные подписи и деловая полиграфия

16.10.2026. Основание: оригинальная матрица ТЗ 0372200172326000015, TZ-043–053. Техническая предконтрактная подготовка, не сдача фирменных носителей.

## Что готово

- [x] 13 отдельных SVG: вход/выход (2), этикетка и аннотация, бланк, билет, две визитки, два бейджа, приглашение, благодарность и открытка.
- [x] 13 векторных PDF-превью с проверенным размером MediaBox.
- [x] Отдельные стрелки входа/выхода, направления визиток/бейджей, редактируемые поля и безопасные заполнители без настоящих ПДн.
- [x] Генератор scripts/generate_secondary_carriers.py и манифест с привязкой к TZ.
- [x] Тесты проверяют число носителей, структуру редактируемых узлов SVG, PDF размеры и отказ при подмене/повреждении файла.
- [x] Добавлена CI-проверка всего пакета, использованы бесплатные python-pptx, pypdf и нативный librsvg без Docker.

## Что не готово

- [ ] Реальные размеры указателей, билета, бейджей, этикеток, данные экспонатов, цены и официальные реквизиты.
- [ ] Предложенные размеры, 3 мм вылетов и 5–12 мм внутренних полей не являются утверждёнными требованиями типографии.
- [ ] Не утверждены фирменный стиль, графика, шрифты и права; не сделаны реальные CMYK/300dpi печатные мастера.
- [ ] Не готово редактирование в приложениях музея, клиентское UAT, документация о передаче прав и подписанные акты.
