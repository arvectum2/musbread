## Тесты и строгие границы результатов

- Новые Laravel `MuseumEntryEditorTest` + `MuseumSectionExportTest`: создание через MoonShine редактором с назначением, экспорт/скрытие черновиков, перенос между разделами, закрытый предок.
- `scripts/qa_dynamic_navigation.py`: временная вложенная структура плюс **новая CMS-страница** и независимый материал, проверка полученной Next.js-статики и ссылок, затем **обязательное восстановление исходного опубликованного JSON и повторная сборка**.
- `apps/web/e2e/tz197-240-accessibility.spec.ts`: 10 E2E, включая 90 комбинаций reflow, клавиатурные сценарии, контраст и сохранение настроек. E2E также запускается в GitHub CI через стандартный `npm run test:e2e`.
- Ни одного изменения в закрытой продакшен-БД музея и никакой публичной публикации. Демонстрационный сайт по-прежнему `noindex`.
- **Нельзя называть 90 CSS-reflow проверок сертификацией ГОСТ или полным нативным zoom-тестом.** Реальная приёмка/инфраструктура — отдельные внешние блокеры.
