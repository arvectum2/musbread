## TZ-242 — технически готово

Сохранён лаконичный нейтральный прототип без autoplay, iframe и рекламных скриптов. Добавлен audit_lightweight_ui.py: анализ всех экспортированных HTML, запрет сторонних JS, iframe/embedded объектов, autoplay, preload видео и тяжёлых data:image, лимиты общих JS не более 2 MiB, одного чанка не более 512 KiB, медиафайла не более 5 MiB, запрет symlink-ассетов. Пять Python unit tests содержат положительный случай и отрицательные случаи на iframe, remote tracking, autoplay, oversized chunks/media и symlink. Реальный результат: 80 HTML страниц, 17 JS файлов, 688383 байт JS (около 672 КиБ), ноль нарушений. Reduced-motion CSS не включает плавную прокрутку или анимации, в Playwright проверяется computed CSS. Визуальный стиль окончательного музея и Web Vitals должны утверждаться отдельно.

## TZ-251 и TZ-260 — технически готовы

Вместо разных случайных границ шапки, hero, внутренних страниц, closing-banner и футера введены общие responsive переменные CSS: museum-shell-width 90%, museum-gutter clamp(1rem,3vw,3.5rem), museum-section-gap clamp(2.25rem,4.4vw,5rem), museum-layout-gap clamp(1rem,2vw,2rem). Подвал сохраняет фон full bleed, но его колонки точно выровнены по контенту. В ходе проверки выявлено реальное горизонтальное переполнение на 10 CSS px в 320px-странице «Музей»: исправлена переносимость длинных названий карточек, текст не обрезается.

Новый браузерный Playwright test проверяет 8 групп маршрутов на 6 ширинах 320, 390, 768, 1024, 1440 и 1920px: границы header/main/footer расходятся не более чем на 1.6 CSS px; padding симметричен и не меньше 12px; shell не уже 80% viewport; нет горизонтальной прокрутки и пересечения футера с main. Проверена функциональность режима reduced-motion. Действующая изолированная MoonShine E2E проверяет conditional CMS sidebar. Не создан второй несовместимый шаблон и не выдумана финальная фирменная сетка.

## TZ-136 — остаётся частично, ждём материалы музея

Действующая медиатека и галерея показывают только одобренные CMS-изображения с alt и подписью. Обложки событий переиспользуют уже утверждённый WebP, без дублей файлов. Действующая официальная страница видео доступна по адресу https://muzei-xleb.ru/video; в нашем справочном разделе есть ссылка на первоисточник. Но это не разрешает импортировать архив, скачивать/хостить видео или внедрять внешние trackers. Для окончания нужны оригинальные фото/видеозаписи, их права и авторство, список разрешённых форматов/площадок, утверждённая структура раздела и редакционная приёмка. TZ-136 остаётся жёлтым и передан в ожидание заказчика — в самостоятельной технической очереди он не должен оставаться без материалов.
