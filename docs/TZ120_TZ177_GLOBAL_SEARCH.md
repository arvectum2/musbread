# TZ-120 / TZ-177 — полный публичный индекс и автодополнение

16 октября 2026. Исходное описание объекта закупки №0372200172326000015: **TZ-120** — п. 2.2.3.6.1, строка **172**, кнопка поиска по всему сайту в шапке, **P0**; **TZ-177** — п. 2.2.3.6.2, строка **234**, умная поисковая строка с автодополнением, **P0**. Сверено по `docs/tz-audit/requirements.psv` **до изменений в коде**. Никакого отношения к отложенным CP-52D-фильтрам редакторских задач.

## Сделано

- Оба экземпляра `GlobalSearch` используют **единый статический индекс из ровно того же публичного `published.json`**, по которому строятся действительные маршруты. Никаких запросов к защищённой CMS / админке / внешним API или индексации черновиков.
- Покрыты главная, дерево опубликованных (или явно предконтрактных) справочных разделов `/guide/`, реальные видимые справочные адреса/телефон/режим/доступность, все пять корневых коллекций (новости, музей, экскурсии, выставки, документы), афиша с прошедшими событиями, страницы опубликованных событий и CMS-материалов, полный текст открытой публикации, H1, анонс, ALT/подписи фотографий, ярлыки загруженных документов и их пользовательские примечания о доступности.
- **Файлы вложений, имеющие опубликованную привязку к странице**, индексируются **отдельными результатами со ссылкой для скачивания**. Только разрешённые content-addressed пути `/documents/<sha256>.(pdf|docx|xlsx)`, формат сверяется с расширением; поиск по названию документа одновременно находит его родительскую публичную страницу. Запрещённые/внешние пути не индексируются. Внутренний текст *самих бинарных файлов* не извлекается и пока не обещается.
- Только реально опубликованный полноценный английский перевод индексируется с прямым маршрутом `/en/.../`. Отсутствующие переводы не выдумываются.
- В шапке есть **кнопка «Найти»** и сочетание Enter с переходом на `/search/?q=...`; на странице полного поиска запрос считывается из URL **после гидратации**, отображается полная выдача и можно просматривать автодополнение. Клавиши стрелок, Enter, Esc поддержаны и проверены, включая сразу ArrowDown+Enter; прямой файл открывается как скачивание. Поиск работает в офлайн-режиме внутри уже собранного сайта.
- Сохранили существующие robots/noindex, CSP и запрет преждевременной индексации предконтрактного сайта; индексация в поиске сайта не равна разрешению поисковым роботам.

## Что ещё требуется по ТЗ

**TZ-120 и TZ-177 остаются «Частично»:** вместо актуального музейного контента пока прототип/утверждённые демонстрационные данные; полноценные сканы/документы, тексты и права на них заказчик не предоставил. Встроенный индекс покрывает **названия** прикреплённых PDF/DOCX/XLSX, но не полнотекстовую распаковку самих файлов. Не проведена UX-проверка музейными сотрудниками и посетителями, не согласованы правила включения архивных данных и реальные требования к поисковой морфологии. Все эти аспекты следует валидировать с музеем до сдачи. Дополнительно требуется сопоставить UX с TZ-245/248.
