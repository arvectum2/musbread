# MusBread — реестр происхождения результатов и прав

**Черновик для внутреннего контроля, не юридическое заключение.** Нельзя распространять обещание «все права наши» на библиотеки, чужие фото, документы и ещё не созданный дизайн.

| Группа | Фактическое состояние | Возможная передача | Обязательная проверка |
|---|---|---|---|
| Собственные Laravel/Next.js компоненты | Код в Git | Исключительные права только на оригинальный код при подтверждённой цепочке прав | Авторство, подрядчики, состав коммитов/акта |
| Тесты, скрипты, документация | В Git | Собственные оригинальные результаты | Отделить заимствования |
| Логотипы/брендбук | Пока только PDF-каркасы, **не реальная айдентика** | После интервью только реально созданные и принятые исходники | Письменное решение, шрифты, изображения и лицензии |
| Laravel, MoonShine, Next.js | Сторонние библиотеки | Лицензионное использование, НЕ исключительные права Arvectum | Проверить точные версии и уведомления |
| HTMLPurifier | Сторонний компонент LGPL согласно THIRD_PARTY.md | В рамках лицензии | Способ распространения, обязательные уведомления |
| TinyMCE в MoonShine | Риск GPL, отдельно описан в THIRD_PARTY.md | Не считать собственным кодом | Юридическая проверка / замена до передачи |
| Фото, архивы, тексты музея | Пока не получены | Только с правами и разрешением музея | Отдельные подтверждения на каждый материал |
| API билетов | Поставщик неизвестен | Права на внешний API не передаются | Лицензии, комиссии, согласование |
| Пароли/данные посетителей | Не в публичном Git | Только закрыто, по согласованию | Никаких секретов/ПДн в архиве |

Перед итоговым актом: подтвердить цепочку прав на авторский код, инвентаризировать лицензии по lock-файлам, получить права на фото/шрифты, отдельно поименовать передаваемые результаты и согласовать момент перехода прав по контракту. Наличие этого файла НЕ означает правового аудита.

Связанные документы: docs/THIRD_PARTY.md, docs/handoff/ACT_RIGHTS_DRAFT.md, docs/research/CUSTOMER_ASSETS_REGISTER.csv.
