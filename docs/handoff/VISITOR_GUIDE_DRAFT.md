# TZ-316 · Инструкция посетителю сайта Музея хлеба (рабочая редакция)

**Статус:** инструкция к существующей демонстрационной статической версии MusBread, 17.10.2026. Это ещё не официально введённый в эксплуатацию сайт. Музей не подтверждал наполненность/сервисы, цены могут меняться; итоговое руководство и скриншоты потребуют его согласования.

## Что работает на демонстрационном сайте
1. **Разделы.** На главной странице откройте меню «Музей», «Посетителям», «Афиша», «Экскурсии», «Детям», «Выставки», «Наука». Подразделы открываются ссылками; сверху внутренних страниц есть «хлебные крошки». Некоторые рубрики — пока каркас по ТЗ, без официального содержимого.
2. **Поиск.** Нажмите поиск в шапке, введите тему; стрелки переключают предложения, Enter открывает выбранный результат, Escape закрывает подсказки. На странице результатов выводятся материалы доступной статической версии; поиск **не гарантирует** присутствие данных из PDF/DOCX.
3. **Афиша.** Из списка можно открыть карточку мероприятия; карточка **не подтверждает** действительность мероприятия и свободные места, пока музей не передал актуальную программу.
4. **Доступность.** Кнопка для слабовидящих изменяет оформление, а Tab / Shift+Tab / Enter помогают управлять ссылками и меню. Это не сертификат соответствия ГОСТ и не гарантирует доступности всех вложений.
5. **Документы.** Перейдите в «Официальные документы»; ссылки ведут к страницам или файлам официального сайта музея. Текст документов не переиздаётся без подтверждения их редакций заказчиком. Формат документов требует соответствующей программы для чтения.

## Чего пока нет
Новый статический сайт не является системой приёма заявлений или бронирований; формы гостей, оплата, транзакции, полный английский перевод и доказательство доступности всех PDF **не введены в эксплуатацию**. Пользовательский аккаунт на демонстрации создавать не нужно.

## Как использовать источники без дублирования
Пока соответствующий раздел уже есть на https://muzei-xleb.ru/, переходите по ссылке на него, а не полагайтесь на неутверждённый новый текст. Дизайн сайта может быть обновлён по результатам согласования, но официальные сведения остаются за музеем.
