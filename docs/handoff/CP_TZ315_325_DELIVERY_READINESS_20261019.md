# TZ-315–325 · Сверка текущего комплекта передачи с фактическим кодом

**19.10.2026. Состояние — только pre-award preparation. Не документ заказчика и не акт передачи.**

В текущем Composer.lock и CMS vendor нет старого TinyMCE; вместо него фактически установлен self-hosted **Jodit Community 4.18.4 MIT**, приложен LICENSE.txt. В реестре CycloneDX сейчас **559** записей. Проведена синхронизация описания редактора и прав с реальным кодом (RIGHTS_MATRIX.md, EDITOR_REPLACEMENT_DECISION.md, ADMIN_GUIDE_TEMPLATE.md, EDITOR_GUIDE_TEMPLATE.md, ACTUAL_DELIVERY_BUILD_GATES.md, ACT_RIGHTS_DRAFT.md и README). Старые разделы CP-33D–35D со статусом GPL TinyMCE остаются только историческими, их нельзя предъявлять как актуальный состав.

Фактически имеется: локальный Git-источник, Laravel/MoonShine/Jodit и Next.js; текущие unit/E2E и нагрузочные протоколы; проект руководств администратора/редактора/посетителя; шаблон акта; реестры сторонних лицензий и исходных музейных файлов. Юридическое заключение/права на шрифты, свидетельства согласия музея, финальный дизайн и реальная поставка **отсутствуют**.

Перед подписанием акта требуется:
- Сверить по тексту точную форму Приложения 1 к ТЗ; шаблон исполнителя её не заменяет.
- Согласовать поимённый перечень **собственных** результатов, исходный Git SHA, контрольные суммы, бумажные/дисковые/облачные носители и получение.
- Не переуступать исключительные права на Jodit, Laravel, MoonShine, Next.js, внешнюю платформу ВМузей, музейные исходные фото/сканы, чужие шрифты.
- Финальный SBOM собирать по реально поставляемому Linux runtime/ассетам, сохранять MIT/прочие уведомления.
- Подготовить скриншоты утверждённого интерфейса и провести обучение сотрудников музея, обновить руководства только по принятой CMS.

**Текущий результат: исправлены устаревшие сведения в подготовительных документах; официальная стадия TZ-315–325 НЕ объявлена завершённой.**
