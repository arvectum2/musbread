## Дефекты, исправленные этим проходом

- Автодополнение афиши не поддерживало управление стрелками. Добавлен выбор с сохранением фокуса поля, Enter, Escape и читаемые ARIA-атрибуты.
- Некоторые браузеры очищали поисковое поле по Escape, хотя пользователь ожидал только закрытия подсказок. Теперь запрос сохраняется.
- Ссылка Контакты на внутренних страницах вела к отсутствующему местному якорю; теперь ведёт на главную.
- Быстрые Chrome-тесты вводили текст ещё до гидратации. Теперь интерактивность отмечается data-ready и тест дожидается неё.
- Проверка установленного Chrome первоначально использовала устаревшую CSP от предыдущего Next.js build. Все браузерные npm-команды пересоздают соответствующие SHA-256 перед запуском. Нестабильный параллельный запуск Chrome заменён последовательным.

## Оставшиеся ограничения

- Нативный Safari проходил только короткую навигационную проверку. Ручной Safari с масштабированием 200%, VoiceOver, визуальное сравнение всех страниц, проверки Chromium-GOST и контроль окончательной доступности не завершены. Chromium-GOST не установлен на Mac mini.
- Нет утверждённых концепций фирменного стиля, полного реального наполнения музея и билетного API; UX с настоящими участниками не проводился.
- Двухконтурная инфраструктура и защищённый канал музея не развернуты; firewall/TLS, нагрузка и пентест не проверены в целевой сети.
- Правовые вопросы GPL TinyMCE и передачи исключительных прав остаются для согласования.
- Этот документ не подтверждает полное выполнение ТЗ и не заменяет официальный протокол приёмки.

## Как повторить

Сначала собрать apps/web командой npm run build, затем выполнить npm run test:e2e, npm run test:webkit и npm run test:chrome из apps/web. Проверить ссылки командой python3 scripts/audit_static_navigation.py apps/web/out из корня. Native Safari на Mac mini: sh scripts/qa_native_safari.sh. Для проверки CMS: python3 scripts/qa_cms_browser.py.

Playwright сохраняет скриншоты/trace локально; GitHub Actions хранит браузерные PNG в артефакте musbread-public-browser-evidence (7 дней). Код и данные проекта публичны, пароли и записи реальной БД в Git не коммитятся.
