# CP-27D — SVG, XLS, EN и доступность документов

15.10.2026. Предконтрактный прототип по требованиям закупки №0372200172326000015. Не означает промышленную приёмку или сертификацию PDF/UA.

## SVG → WebP

- [x] Бесплатный нативный librsvg (rsvg-convert) установлен на Mac mini, CMS CI ставит Linux librsvg2-bin.
- [x] Инспектор MuseumSvgRasterizer допускает только ограниченные статические примитивы svg/g/path/rect/circle/ellipse/line/polyline/polygon/title/desc и белый список атрибутов.
- [x] Отклоняются DTD/XXE, скрипты, CSS, внешние ссылки, изображения, обработчики событий, анимация, foreignObject.
- [x] Ограничены 100 КБ входа, размеры до 2048×2048, 4 млн пикселей, 700 узлов, глубина 18, 4-секундный таймаут рендеринга.
- [x] В хранилище отправляется только перекодированный WebP, исходный SVG не публикуется. Проверены обычный вектор и негативные примеры.
- [ ] Сложные SVG с градиентами/шрифтами/фильтрами, анимированный GIF, видео и промышленный security/fuzz аудит пока не поддерживаются.

## Legacy XLS → XLSX

- [x] В dev-only режиме Python-конвертер normalize_xls.py читает OLE2 XLS через xlrd 2.0.2, создаёт новый XLSX только со значениями.
- [x] Формулы, макросы, объекты, форматирование и внешние ссылки не переносятся; похожие на формулу строки остаются строками (inlineStr), не выполняются.
- [x] Ограничены исходный размер 5 МБ, 12 листов, 10 000 строк, 128 столбцов, 50 000 непустых ячеек; отдельный процесс с таймаутом 9 секунд.
- [x] Выходной XLSX проверяется существующим инспектором; SHA-256 и источник XLS сохраняются как метаданные. Исходный XLS не сохраняется.
- [x] В production загрузка legacy XLS НАМЕРЕННО ЗАПРЕЩЕНА до AV/CDR и одобрения изменений формата музеем.
- [ ] Реальные XLS музея не проверены. Парсер xlrd не антивирус; AV/CDR и условия изоляции согласовать после победы.

## RU/EN

- [x] Два отдельных корневых Next.js layout (ru)/(en) без смены русских URL; HTML русской версии lang=ru, английской lang=en.
- [x] Английские шапка, футер, метки навигации, переключатель контраста и список только действительно опубликованных переводов.
- [x] Русская/английская пара имеет раздельные SEO и hreflang. Временный QA-перевод успешно собран и полностью удалён после проверки.
- [ ] Нет полного английского контента/проверенных переводов разделов, EN поиска и утверждённых английских alt.
- [ ] Next.js static export при нуле переводов генерирует техническую страницу /en/museum/not-translated/. Nginx-шаблон блокирует её с HTTP 404, а простой локальный HTTP-сервер отдаёт HTML с 200. Ссылка исключена из меню и sitemap, страница noindex.

## Доступность документов

- [x] Текстовая альтернатива accessibility_note и признак ручной проверки accessibility_reviewed в CMS.
- [x] Нельзя подтвердить проверку без осмысленного пояснения от 40 символов. Действуют прежние section-level ACL.
- [x] На статической странице документа выводится пояснение либо указание, что доступность ещё не проверена.
- [ ] Это не проверка PDF/UA, не тегирование PDF и не экспертиза соответствия ГОСТ. Автоматической генерации корректных alt пока нет.

## Проверки, стоимость, заказчик

Применены две миграции локальной SQLite на Mac mini. Проверяются PHP/Python/Next.js/Playwright/Nginx и SHA-256 целостность. Дополнительные коммерческие расходы 0 ₽. Docker не использовался. В публичный Git не загружались реальные документы заказчика или персональные данные.

От музея необходимы: утверждённый AV/CDR, решение по XLS values-only, реальные проверочные файлы, требования к SVG/GIF/видео, официальные английские тексты/alt, PDF и методика оценки доступности.
