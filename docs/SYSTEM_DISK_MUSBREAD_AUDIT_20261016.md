## Что обнаружено

В предыдущих чекпоинтах использовались `/private/tmp/musbread*`: локальные ZIP до подачи заявки, демонстрационные сборки, копии SQLite до миграции, текстовые задачи и заметки, изображения-превью, промежуточные конвертации XLSX и диагностические логи. Всего обнаружено около 533 корневых временных файлов (~26,5 МБ), а также несколько временных директорий с инструментами и их зависимостями.

Проверена временная копия **`/private/tmp/musbread-cp44-stage-20261016`** (около 690 МБ с установленными зависимостями): Git-дерево чистое, HEAD `ca4b0c8` и этот коммит уже входит в актуальную ветку Git основного репозитория на ArvectumSSD (`git merge-base --is-ancestor`). Таким образом, уникального незакоммиченного исходного кода в этой копии нет; пакеты `node_modules`, `vendor` и опубликованные CMS assets — генерируемые зависимости, их повторная передача не требуется.

## Перенос и проверка

Материалы собраны в **`/.local_archive/system-disk-20261016/system-disk-artifacts.tar.gz`** внутри репозитория на SSD. Содержит 2 977 элементов (в том числе 2 639 обычных файлов) из `/private/tmp/musbread*` за исключением дублирующего чистого Git-дерева. Архив примерно 40 МБ, проверен командой `tar -tzf` и чтением gzip; SHA-256 записан в соседний приватный `inventory.json`. Приватный каталог с режимом доступа `0700` игнорируется Git через `/.local_archive/`.

Для изучения (не распаковывать в самую корневую папку исходников):

```bash
cd /Volumes/ArvectumSSD/arvectum/repos/musbread
cat .local_archive/system-disk-20261016/inventory.json
tar -tzf .local_archive/system-disk-20261016/system-disk-artifacts.tar.gz | less
# Распаковать при необходимости в отдельный закрытый каталог:
mkdir -p .local_archive/system-disk-20261016/extracted
(cd .local_archive/system-disk-20261016/extracted && tar -xzf ../system-disk-artifacts.tar.gz)
```

**Очистка системного диска выполнена после верификации.** Приватный архив перечитан и повторно сверены все 543 корневых временных файла; сохранена резервная история старого Git через `old-stage-git.bundle` (`git bundle verify`). После этого из `/private/tmp` удалены эти 543 файла, пять вспомогательных каталогов и дублирующая чистая Git-копия (673 МиБ). Остались основной проект и приватные архивы только на ArvectumSSD. Автоматически заново создаваемые временные логи будущих проверок не считаются потерянными исходниками; для повторной уборки понадобится новый архив.
