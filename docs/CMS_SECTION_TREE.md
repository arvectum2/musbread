# TZ-C02 — дерево разделов и права редакторов MoonShine

Основание: исходное ТЗ №0372200172326000015, п. 2.2.3.2 и раздел 4. Реализация на Mac mini, без Docker и платных расходов. Это предварительная реализация CMS, НЕ готовая система заявок/обращений.

## Что создано

- Таблица museum_sections: slug, title, parent_id, sort_order, status, legacy_path. Глубина вложенности не ограничена двумя уровнями; стабильные URL по slug.
- Таблица museum_section_editor: назначение сотрудника MoonShine на конкретный раздел. Права по умолчанию запрещены и НЕ наследуются дочерними разделами автоматически.
- Поле museum_entries.museum_section_id связывает публикацию и её раздел. Старые тестовые записи без привязки продолжают работать ради обратной совместимости.
- Ресурс «Структура сайта» в MoonShine. Только superuser может создавать, изменять, переносить и удалять пустые разделы и назначать редакторов. Нельзя создать цикл parent→child→parent, удалить ветку с материалами/детьми или указать внешний legacy_path.
- Форма «Материалы музея»: редактор выбирает только свои разделы, чужие записи и редактирование по прямым HTTP-адресам защищены. Администратор видит все.
- Экспорт museum:export публикует только approved-разделы, у которых также одобрена вся цепь предков; материалы в закрытой ветке не выдаются. Пользовательские данные, email, таблицы прав и черновики не попадают на публичный сервер.
- Next.js принимает sections из exported JSON и динамически генерирует 7-групповое меню, подстраницы, breadcrumbs, поиск и будущий sitemap. Если CMS-секции отсутствуют в снимке, остаётся fallback на исходную структуру muzei-xleb.ru. Если CMS-секции есть, но все они черновые, пустое дерево не заменяется старым меню.

## Как пользоваться локально

    cd /Volumes/ArvectumSSD/Arvectum/repos/musbread/apps/cms
    php artisan migrate --force
    php artisan db:seed --class=ReferenceMuseumSectionsSeeder --force
    php artisan museum:export

При первом запуске opt-in seeder загружает 62 элемента: 7 верхних разделов и 55 подразделов по исследованному действующему сайту и требованиям нового ТЗ. При повторном запуске existing records не перезаписываются. Seeder отказывается запускаться в production.

В MoonShine открыть раздел «Структура сайта». В форме можно изменить название, slug, порядок, родителя, статус и назначить сотрудников через поле «Назначенные редакторы». Затем редактор открывает «Материалы музея» и привязывает запись к одному из разрешённых разделов. Публикация с очередью и проверкой SHA-256 работает по прежнему процессу.
