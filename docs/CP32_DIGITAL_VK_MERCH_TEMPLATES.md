# CP-32D — цифровые, VK и сувенирные нейтральные шаблоны

Дата 16.10.2026; основание — исходное ТЗ №0372200172326000015, TZ-034–037 и TZ-059–061, реестр 113 целей DESIGN_DELIVERABLES.csv.

## Готовая техническая подготовка

- [x] 16 редактируемых SVG и 16 PNG: одна цифровая афиша сайта, аватар VK, обложка VK, 4 композиции VK для будущих рубрик, 9 сувениров.
- [x] У сувениров разные векторные контуры и независимые зоны будущего нанесения; у VK — отдельная условная зона мобильной обрезки и номера рубрик вместо выдуманных названий.
- [x] Все позиции привязаны к исходному пункту ТЗ и конкретной позиции из поштучного реестра.
- [x] Манифест содержит размеры и SHA-256 каждого PNG, отсутствие персональных данных и явные флаги неподтверждённых размеров.
- [x] Шесть негативных/структурных тестов проверяют XML, реальные PNG размеры, редактируемые элементы, хеши, подмену манифеста и отказ при попытке зачесть TECH_-файл как утверждённый макет.
- [x] Проверки добавлены в GitHub Actions. Бесплатный нативный rsvg-convert на Mac mini, без Docker.

## Не выполнено по контракту

- [ ] Размеры холстов условные, не прямо указанные в ТЗ и не проверенные на действующем VK; мобильная обрезка лишь гипотеза.
- [ ] Нет официальных названий рубрик, настоящего бренда, лицензированных изображений и согласованных текстов.
- [ ] Сувениры являются схематическими примерами, НЕ промышленными лекалами, развёртками или макетами реальных изделий.
- [ ] Нет печатных профилей, реальных производственных размеров, пробников и прав на финальные бренд-материалы.
- [ ] Все 113 финальных бренд-носителей остаются в статусе 0 согласовано заказчиком; DESIGN_EVIDENCE.csv не содержит новых результатов.
