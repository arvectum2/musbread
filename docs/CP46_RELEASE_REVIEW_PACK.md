# CP-46D — единый предпубликационный пакет для редактора

16 октября 2026 · №0372200172326000015 · внутренний доконтрактный этап. **Не** подтверждение музейной приёмки, **не** электронная подпись, **не** реальная публикация сайта.

## Реализовано

- В закрытом сравнении версий MoonShine появилась ссылка **«Скачать единый JSON-пакет редакторской проверки»**. Маршрут `/admin/museum-content/release-review.json` использует существующий MoonShine Authenticate, работает только при наличии неизменённого, подтверждённого локального снимка CP-44D. При отсутствии или подмене базы возвращается `409`, а не фиктивный перечень изменений.
- Содержимое берётся из read-only `MuseumPublicationDiff` и `MuseumContentPreflight`, таким образом оно согласовано с CP-42D/CP-43D/CP-44D/CP-45D. Включены: ID локального проверенного релиза, SHA-256 исходного и подготовленного снимков, состояние автоматической проверки (критические ошибки и рекомендации), количество доступных объектов, сводка «добавится/изменится/исчезнет», только **затронутые** материалы/события/разделы, список исчезающих RU/EN URL с `suggested_redirect = null`.
- **Никаких черновых HTML-текстов, приватных вложений, конфигурационных секретов, учётных данных или неавторизованных редактору разделов**. Editor ограничен ранее выданными ему разделами; полный структурный отчёт — только superuser. События наследуют глобальные полномочия существующего ресурса MoonShine — отдельный ACL по событиям остаётся в задачах после согласования музеем.
- Пакет `{ document, sha256 }`, где `sha256` считается от сериализованного объекта `document` в UTF-8 JSON (`JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES`). Эта сумма служит только обнаружению случайной порчи/рассогласования и **не является защищённой цифровой подписью**. После правок контента изменяется SHA-256 подготовленного снимка. Пакет не помечает материалы «утверждёнными» автоматически, даже если критичных замечаний нет.
- `Content-Disposition: attachment`, `application/json`, `private, no-store`, `noindex, nofollow`, `nosniff`, CSP `default-src 'none'`, отказ гостям. Нет очереди релиза, перенаправлений, временного постоянного файла, новых миграций или платных зависимостей. Вызов использует существующий временный CMS-экспорт CP-44D, и его файлы удаляются после создания отчёта.

## Проверки

`MuseumPublicationDiffTest` +3: пакет и его SHA-256, обновление отпечатка после редактирования, реестр старых URL без выдуманных редиректов, запрет для гостей и отсутствие подтверждённой базы, запрет чужих материалов/секций для Editor, неизменность исходной статики и отсутствие действий в очереди. Браузерный `scripts/qa_cms_browser.py` проверяет скачивание приватного JSON из реальной авторизованной CMS, другие тесты продолжают проверять общий цикл CMS → статический сайт.

**Границы:** сравнение только с локальным стендом, не с размещённым сайтом музея. Нет утверждения фактической/юридической точности, прав на контент, полного UX/WCAG-аудита или внешних ссылок. После заключения контракта решение по URL и окончательное утверждение всех музейных данных принимает заказчик. Затраты 0 ₽, TinyMCE не изменялся.
