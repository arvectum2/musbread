Проверка 18.10.2026. Источники: действующий сайт https://muzei-xleb.ru через Mac mini, SHA-256 и длина каждого файла сравнены с ранее сохранённым закрытым оригиналом на внешнем ArvectumSSD.

**Это технический preflight, а не сертификация PDF/UA, ГОСТ Р 70176-2022 или постановления № 102.** Наличие текстового слоя не доказывает доступность семантической структуры, языка, таблиц, порядка чтения и графических альтернатив. Тегированный PDF тоже требует ручной проверки вспомогательными технологиями.

- Проверено исходных документов: **44**.
- Форматы: PDF **42**, DOCX **2**.
- PDF с Tagged: yes — **0**, без тегов — **42**, неизвестно — **0**.
- Есть извлекаемые 150+ букв/цифр на первых трёх страницах (приближённая оценка, не ГОСТ): **2** PDF.
- Недостаточно извлекаемого текста в первых трёх страницах (возможны сканы, титульные листы или краткий PDF): **40**.

## Первые действия по устранению

Для PDF без структурных тегов нельзя выдавать обычный текстовый слой за доступный PDF. Требуется согласованный с заказчиком способ: исправление тегов/закладок/порядка чтения и проверка экранным диктором либо точная эквивалентная HTML-версия.
Для документов с подозрением на сканы нужна визуальная проверка страниц, правомерный OCR при необходимости и обязательная вычитка фактического официального текста, без генерации вымышленных юридических формулировок.
DOCX тоже требуют отдельной проверки заголовков, таблиц, alt и корректной последовательности чтения.

Полная таблица с официальной страницей, URL, названием, SHA-256, размером, числом страниц, признаками PDF Tagged и ограниченными текстовыми пробами: [OFFICIAL_PDF_ACCESSIBILITY_PREFLIGHT.csv](tz-audit/OFFICIAL_PDF_ACCESSIBILITY_PREFLIGHT.csv).
