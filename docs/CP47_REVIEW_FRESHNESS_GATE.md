# CP-47D — защита экспорта от устаревшего предпубликационного отчёта

16 октября 2026 · закупка №0372200172326000015 · внутренний доконтрактный этап MusBread. **Ни эта проверка, ни SHA-256 отчёта не являются подтверждением заказчика, квалифицированной электронной подписью или гарантией отсутствия конкурентного изменения БД.**

## Как пользоваться

1. В приватной CMS войти под **администратором** и открыть «Материалы музея → Сравнить → Скачать единый JSON-пакет редакторской проверки» (CP-46D). На Mac mini сохранить его в приватной директории, недоступной через публичный webroot.
2. После редакторского рассмотрения проверить **актуальность** отчёта, не выполняя публикацию:

   ```bash
   cd apps/cms
   php artisan museum:verify-review /private/path/to/musbread-release-review.json
   php artisan museum:verify-review /private/path/to/musbread-release-review.json --json
   ```

3. При необходимости **строго ограничить** ручную выгрузку именно этой проверенной версией:

   ```bash
   php artisan museum:export --preflight-strict \
     --review-pack=/private/path/to/musbread-release-review.json
   ```

   Данный вызов использует обычные настройки путей CMS-экспорта; *без флага `--review-pack` поведение старого конвейера не менялось*. Для альтернативных путей можно указать `--output`, `--manifest`, `--media-output-dir`, `--document-output-dir`.

## Проверки

- Приватный JSON — только **полный** пакет администратора (`scope = all`), а не редактора отдельной рубрики. Проверяются формат/размер/отсутствие симлинка, SHA-256 объекта документа, наличие проверенной локальной базы и пересчитываются все данные, включая **текущий** content snapshot SHA-256, локальный release ID, весь список изменений и preflight-показатели. Также не допускаются критичные замечания по готовым материалам или событиям.
- Код 0 CLI означает только: «этот сохранённый документ всё ещё описывает текущие данные и проходит автоматические критичные проверки». При изменении материала, афиши, релизной базы, контрольной суммы, прав доступа, предрелизного списка URL или критичном замечании проверка завершается **с ошибкой**. Нельзя принять редакторский ограниченный пакет за полный.
- Опциональный `--review-pack` останавливает экспорт **до записи JSON, манифеста, статических медиа/документов** при неверном/устаревшем пакете. Путь вывода фиксируется до вложенной проверки, чтобы внутренний временный экспорт не перенаправил файлы родительского процесса.
- JSON-отчёт несекретный лишь в смысле формата; он содержит внутренние названия и адреса, поэтому хранится **приватно**, не прикладывается в публичный Next.js и не принимается из HTTP-запросов как готовый приказ.
- SHA-256 **не является цифровой подписью**. Любой с доступом к файлу может изменить и пересчитать его сумму; защита базируется также на *независимом повторном расчёте из CMS*. Между проверкой и непосредственно окончательной записью теоретически возможны конкурентные изменения; для реального производственного контура после контракта понадобятся транзакционные гарантии и явный протокол утверждения музеем.
- Автоматическая часовая выгрузка и обычный `museum:export` не заблокированы новым флагом. Это опциональная подготовительная защита для ручного релиза, а не заявка на выполнение всех требований ТЗ.
