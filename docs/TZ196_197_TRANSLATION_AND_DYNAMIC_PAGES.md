# TZ-196 и TZ-197 — проверенная техническая готовность

Исходное ТЗ: приложение №3 закупки 0372200172326000015, пункт 2.2.3.6.3, строка 246: возможность перевода сайта на английский язык и добавления новых страниц в существующие разделы.

## TZ-196 — техническая возможность английского перевода

Laravel/MoonShine поддерживает независимые английские поля заголовка, тела, краткого описания, H1 и SEO, а публичный экспорт пропускает английский перевод только при наличии необходимого содержания. Серверная очистка HTML препятствует публикации script из редакторского содержимого. Next.js генерирует отдельные EN URL, SEO, hreflang и перекрёстные RU/EN ссылки. Неполный перевод не публикуется.

## TZ-197 — новые страницы в разделах

В MoonShine есть создание новых записей и назначение раздела с ACL; экспорт формирует статический маршрут и ссылку с родительской страницы без доработки React. Проверен четырёхуровневый тестовый раздел и новая вложенная страница.

## Проверка реальной цепочки

Скрипты scripts/qa_dynamic_navigation.py и scripts/qa_bilingual_publication.py используют временные искусственные данные, проверяют итоговый HTML и всегда восстанавливают исходный JSON побайтово с проверкой SHA-256. Затем восстанавливают исходную статическую сборку. Тестовые страницы не публикуются на серверах заказчика.
