## Правила публикации прогресса
1. Изменение → локальные тесты → отдельный коммит → GitHub Actions green → комментарий и статус GitHub issue.
2. Исходники и тестовые данные в публичном GitHub/GitVerse; **никаких реальных секретов и материалов клиента**.
3. До 20 октября расходы 0 ₽; работа исключительно с бесплатными инструментами.
4. Официальная айдентика и реальная сеть музея строго после интервью/согласований.
