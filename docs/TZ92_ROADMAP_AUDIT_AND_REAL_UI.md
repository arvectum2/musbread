## Технические изменения и их пределы

**TZ-116, TZ-118, TZ-178 — 🟢.** Существующая шапка уже имела реальный официальный HTTPS URL ВМузей и безопасную внутреннюю ссылку «Доступная среда», но CSS скрывал кнопку покупки на мобильных устройствах в меню. Исправлено: CTA теперь постоянно видна на мобильном и десктопе. Playwright проверяет 12 RU маршрутов на 320, 768, 1440 px, английский переведённый маршрут, безопасность внешнего href, отсутствие горизонтальной прокрутки и видимость обеих функций. Операции оплаты, разрешённые SKU и реальная доступность учреждения остаются отдельными строками TZ-205/273/140/144/286.

**TZ-149, 151, 152, 153 — 🟡.** В существующих разделах афиши «Детям», «Встречи», «Фестивали», «Мастер-классы» вместо пустого только справочного шаблона появилась реально работающая подборка из единого опубликованного снимка CMS. Используется текущий EventAgenda и точная карта категории/section_slug без ложного приписывания возрастов, событий или сроков. Дополнительно обновлены разделы «Экскурсии», «Выставки», «Архив». Демо-данные явно маркированы, при отсутствии официальной программы выводится честное пустое состояние и источник. Тесты: node 2/2, Playwright 5/5. Ждём утверждённое музейное расписание, фотографии/права и редакторскую UAT.

**TZ-129, 130, 131, 141, 144, 156, 157 — 🟡.** Проверены HTTP 200 для существующих реальных страниц истории музея/здания, экспозиции, стоимости, доступной среды, интерактивных и тематических экскурсий. Прототип уже имел соответствующие справочные маршруты, на которые добавлять код не понадобилось; Playwright 7/7 подтвердил реальные источники и честное указание неполноты. Полные тексты и права не переданы, поэтому не отмечено 🟢. Официальные URL FAQ и будущих выставок возвращают HTTP 404, эти требования не повышались.
