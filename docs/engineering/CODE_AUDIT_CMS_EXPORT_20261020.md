# CODE-AUDIT-02 — аудит и рефакторинг Laravel MuseumSnapshot

**20.10.2026, Mac mini, ArvectumSSD; только локальная ветка.** Живой музей, ЕИС, оригинальные документы, домен, SEO, дизайн не изменялись. Новых вопросов музею нет.

## Выполненные изменения

Команда apps/cms/app/Console/Commands/ExportMuseumSnapshot.php сокращена **с 477 до 312 строк**. Четыре вынесенные ответственности:

1. **MuseumSnapshotPreflight.php:** валидация музейных видеовставок WYSIWYG и уже одобренного доступного HTML документов до записи выходных файлов. Неутверждённые видео или изменённый PDF/HTML должны блокировать экспорт.
2. **MuseumPublishedSections.php:** единый fail-closed фильтр для экспорта и списка готовности CMS. Скрывает потомков черновых, отсутствующих или циклических родителей; не меняет частные данные CMS.
3. **MuseumSnapshotSerializer.php:** точная каноническая сериализация JSON версии 1 с кириллицей, стабильным порядком полей, завершающим LF и SHA-256 манифеста. При отсутствии секций сохраняет старый формат без section_count.
4. **MuseumStaticAssetPublisher.php:** отдельный слой копирования и удаления публичных WebP, PDF, DOCX и XLSX с проверками SHA-256/размера/формата/прав/alt. Не использует директории приватных CMS-документов как публичный вывод.

**Исправленная ошибка удаления:** раньше очистка media-каталога удаляла любой WebP без записи в манифесте. Теперь удаляются только файлы со строго 64-символьным SHA-256-именем и расширением webp. Иные фото и служебные файлы сохраняются. Для документов прежняя строгая политика hash.pdf/docx/xlsx сохранена. Отдельные тесты проверяют удаление настоящих сгенерированных файлов и сохранение посторонних.

## P1, отдельно: двухфазная файловая публикация

Унаследованная команда всё ещё записывает и удаляет отдельные медиа/документы до финальной повторной проверки MuseumExplicitApprovalGate::assertUnchanged. При конкурентном изменении утверждённых версий JSON-публикация может отмениться уже после частичной файловой работы. Это **потенциальный race condition**, не заявленная фактическая утечка. Исправление требует отдельного этапа staged/commit, отказоустойчивых тестов, проверки атомарности и отката; не менять вслепую действующий протокол.

Настоящий музей, CMS заказчика, IP, исходные файлы, поисковая индексация, публичное размещение, PII не затронуты. Светофор ТЗ остаётся **325: 🟢85 / 🟡118 / 🔴122**. Нет push и контрактной приёмки.
