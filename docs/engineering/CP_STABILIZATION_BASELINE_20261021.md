## Политика стабилизации (до окончания дизайна и локализаций)

1. **Архитектурная заморозка:** не менять стек Laravel 12 / MoonShine + статический Next.js / Nginx, схему внешних URL, формат CMS-snapshot, сигнатуры одобрений, SHA/lock/rollback и границу изоляции ради чистоты кода. Не переименовывать URL без полноценной карты 301.
2. **Разрешено сразу:** только подтверждённые P0/P1 — безопасность, утечка закрытых материалов, потеря данных, race, сбой обязательной функции ТЗ, ложная документация для заказчика. Каждый баг — минимальная правка + повторяемый тест + проверка статического выпуска. P2/косметику — в список, без изменения работающего ядра.
3. **Следующий продуктовый этап:** сперва согласовать **айдентику/дизайн и структуру** по действующему договору и позиции музея; затем вводить **локализации**, уточнённый контент и CMS workflow; выполнить адресную регрессию после каждого изменения. Эти работы не отменяются заморозкой технической архитектуры.
4. **После согласований:** один ограниченный обзор повторно появившегося дублирования и сложных участков. Рефакторить только при доказанной экономии сопровождения и сохранении обратной совместимости. Не переносить масштабные изменения на самый конец, перед приёмкой.
5. **Перед боевым выпуском:** code freeze, `php artisan test`, Python unittest, TypeScript, ESLint, полный HTML/media/documents/link preflight, npm/composer audit, host-approved HTTPS/redirect preflight, rollback rehearsal, проверка персональных данных и реальных сервисов. Не объявлять UAT/pentest/production SLA успешно пройденными без фактического протокола на оборудовании музея.
6. **Разрешение на production:** только после контракта, инфраструктуры, финальных одобрений и согласованного плана SEO/отката. GitHub push исходников сам по себе **не** является публикацией на домене музея.
