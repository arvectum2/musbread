## Эксплуатационные команды (только Mac mini / закрытый сервер)

```bash
cd /Volumes/ArvectumSSD/arvectum/repos/musbread/apps/cms
php artisan museum:backup --name=before-museum-upgrade
php artisan museum:restore-backup before-museum-upgrade --verify-only
php artisan museum:restore-backup before-museum-upgrade
```

Реальная копия уже есть в закрытом `storage/app/private/backups/tz088-manual-20261016.zip`, проверенное тестовое восстановление — в `storage/app/private/restores/tz088-manual-20261016/`. **Не пересылать архив, не помещать в Git, не публиковать и не считать его внешним/зашифрованным резервированием.** Эти данные могут содержать приватную информацию; хранить под контролем владельца, а не на публичной стороне. У нового CLI отсутствует HTTP маршрут, восстановление живой базы вручную запрещено без согласованной процедуры остановки/блокировки ввода.

Никаких изменений в TinyMCE, фирменном стиле или публичном CMS API. Технические тесты не равны формальной приёмке.
