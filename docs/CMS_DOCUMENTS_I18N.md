# CP-26D — документы, медиатека и английская подготовка

Аудит 15.10.2026 по первичному ТЗ №0372200172326000015: TZ-182, TZ-184, TZ-193, TZ-196, TZ-235, TZ-312. Предконтрактный прототип на Mac mini, 0 ₽, без Docker. Официальных музейных документов или переводов пока нет.

## Выполнено

- [x] Закрытая библиотека документов через /admin/museum-documents с привязкой к музейной публикации (материалу CMS), названием, форматом и размерами.
- [x] PDF/DOCX/XLSX до 15 МБ: сигнатуры форматов, проверки архивных макросов/ActiveX, подозрительных вложений, размера разжатия, имен файлов и проверка SHA-256. Имя при хранении заменяется UUID. Неизвестный формат отклоняется.
- [x] Закрытое скачивание как attachment с application/octet-stream, nosniff и private no-store. Проверка прав редактора на нужный раздел/документ. Запрет удаления статьи с активными файлами.
- [x] Публичный экспорт только после опубликования материала (с одобренной родительской веткой); файлы по хешу, manifest SHA-256, отдельные Download links на Next.js странице. При отзыве публикации статический файл удаляется.
- [x] Отдельная проверка документов в release_site, audit_public_artifacts и Nginx-шаблоне, принудительное скачивание без inline просмотра, security headers.
- [x] Закрыт ранее существовавший пробел ACL в галерее: редактор видит, загружает, меняет, удаляет или просматривает лишь изображения своих разделов.
- [x] GIF можно загрузить, но он перекодируется в первый кадр WebP. Анимация не сохраняется. JPG/PNG/WebP продолжают перекодироваться с очисткой метаданных.
- [x] В CMS добавлены отдельные English title, excerpt, body, SEO title/description. HTML очищается HTMLPurifier как русский. Экспорт только при заполненном английском заголовке и тексте, с обязательным условием публикации исходной записи.
- [x] Сгенерированные страницы /en/[section]/[slug] со своими SEO-тегами и hreflang; переходы RU/EN только у реально переведённых записей. Временная тестовая английская публикация действительно собрана в HTML, затем удалена из исходного JSON и результата чистой сборки.
- [x] Проверка отсутствие приватных путей/авторов и повреждённых документов в публичном релизе. Негативные тесты прав доступа.

## Что сознательно не закрываем в ТЗ

- [ ] Старый XLS (OLE2) небезопасно принимать без согласованного антивирусного/CDR процесса и пока отклоняется. XLSX поддерживается, но не является полной заменой XLS. TZ-184 остаётся ЧАСТИЧНО.
- [ ] SVG пока не импортируется: сырой файл способен содержать скрипты/внешние URL. Анимация GIF не сохраняется, видео нет. TZ-182 только ЧАСТИЧНО.
- [ ] Проверка структуры файла не заменяет антивирус, гарантированную безопасность PDF, право на распространение, тегированный доступный PDF или HTML-альтернативу. Нужен отдельно ГОСТ Р 70176-2022 и процедура AV.
- [ ] Автоматический осмысленный alt для всех картинок отсутствует; пока редактор вводит обязательный ручной alt.
- [ ] Полностью двуязычного сайта нет: основное меню, шапка и футер не переведены. Корневой HTML ещё имеет lang=ru даже на EN-странице, хотя article lang=en. Это надо доработать до приёмки. TZ-196 только ЧАСТИЧНО.
- [ ] Технический 404-маршрут /en/museum/not-translated при отсутствии утверждённых переводов нужен для статического экспорта Next.js; он не связан с контентом, не включается в меню/sitemap и закрыт noindex.
- [ ] Не проведены проверки с реальными документами музея, права на файлы, работа в двух контурах, реальный AV/CDR, нагрузка и UX.

## Как тестировать локально

Из каталога apps/cms запустить php artisan migrate, затем php artisan test --filter MuseumDocumentsTest и php artisan test --filter MuseumEnglishTranslationTest. Из корня репозитория запустить python3 -m unittest discover -s tests -q. Из apps/web — npm run build. Никакие документы заказчика или персональные данные в публичный Git не добавлялись.

## Что нужно от музея

Список оригинальных PDF/DOCX/XLS/XLSX и их права; нужно ли сохранять старый XLS или можно согласовать конвертацию в XLSX; антивирус/CDR и параметры серверов; требования к SVG, GIF-анимации и видео; материалы на английском, срок и ответственные за проверку перевода; политика доступности PDF и альтернативного HTML.
