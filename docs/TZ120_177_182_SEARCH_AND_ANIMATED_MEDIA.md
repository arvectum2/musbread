## Команды, установка и безопасность

При размещении **закрытой CMS** на Linux требуется пакет `librsvg2-bin` и `webp`, содержащий `gif2webp`; установку производит владелец инфраструктуры. CI PHP test job устанавливает оба пакета. Если `gif2webp` отсутствует, загрузка анимированного GIF **явно отклоняется**, без тихой потери анимации. Никаких shell-строк, удалённых URL, сохранённых метаданных исходника, браузерного SVG-кода, публичного CMS endpoint или доступа к приватным медиа не добавлено. Временные файлы создаются с правами 0600 в `storage/app/private`, после конвертации удаляются.

**Тесты:** `MuseumMediaTest` проверяет действительную 2-кадровую GIF89a анимацию, выходной ANIM/ANMF WebP, private preview, экспорт в content-addressed путь и контрольную сумму, запрет GIF с 61 кадром, длительностью за 30 с, лишним HTML после трейлера и оборванным потоком. Регрессионный однокадровый GIF87a, SVG с запретом скриптов/ссылок и контроль ACL сохраняются. Локальный PHP full regression и GitHub CI должны быть зелёными до закрытия этапа.

Никаких новых обязательств вне первичного ТЗ: сторонний полнотекстовый индекс бинарных PDF/Office файлов не строится. UI TinyMCE и публичный домен заказчика не изменены.
