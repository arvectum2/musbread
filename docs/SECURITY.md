# MusBread — отчёт pre-award security gates

Статус: технические проверки прототипа от 15.10.2026. Не акт пентеста и не подтверждение безопасности инфраструктуры заказчика.

## Реализовано

- Роли Admin/Editor, отрицательные HTTP-тесты доступа к системным пользователям, ролям и закрытой медиатеке.
- В WYSIWYG используется HTMLPurifier при сохранении, при сборке статического HTML — sanitize-html; отрицательные XSS-тесты script/iframe/javascript URL/onclick.
- Laravel MoonShine login: IP-бюджет 8 POST в минуту (включая смену логинов), media upload: 30 POST в минуту. Ответ 429 с Retry-After. У MoonShine есть и собственное ограничение по паре username/IP.
- Playwright с авторизованной сессией проверяет отклонение POST в медиатеку без CSRF-токена (419).
- Подозрительный SQLi-подобный slug отклоняется до сохранения; БД используется через Eloquent.
- Публичный Next.js строит только утверждённые записи. Внешние медиа выпускаются как WebP с SHA-256; секретный gate проверяет артефакты static build.
- CSP строится из SHA-256 всех встроенных JS фактической сборки; script-src-attr none, object-src none, frame-ancestors none, base-uri none. Playwright Chromium и WebKit проверяют hydration/поиск под CSP и отдельно подтверждают блокировку внедрённого постороннего inline-скрипта.
- Nginx: CSP и общие security headers для статических путей, приватная CMS только на localhost, отдельные POST rate-limit zones. CI проверяет nginx -t и HTTP smoke.
- Composer audit и production npm audit запускаются при push.

## Ограничения и блокеры

- CSP оставляет style-src unsafe-inline для CSS. При увеличении числа страниц заголовок может стать слишком большим: перед промышленным запуском нужны нагрузочные и функциональные проверки. Политика хешей должна устанавливаться и перезагружаться одновременно с каждой статической сборкой, включая rollback.
- Полный npm audit ранее находил предупреждения в dev-инструментах; production audit не доказывает отсутствие всех уязвимостей.
- Физическая изоляция, firewall, HTTPS/HSTS, IP whitelist, реальное резервное копирование и pentest не проверялись без доступа к инфраструктуре музея.
- Лицензия GPL у TinyMCE требует проверки до передачи исключительных прав.

Бюджет предварительных проверок: 0 ₽. Цена независимого pentest пока неизвестна и в рабочую смету не включена.

## Регулярная проверка зависимостей — TZ-094 (17.10.2026)

Изначально настроены npm production audit и Composer locked audit при push в CI. Новый отдельный workflow `.github/workflows/dependency-review.yml` повторяет эти проверки еженедельно по понедельникам и допускает ручной запуск. Права Actions ограничены чтением репозитория. Ни один job не обновляет lock-файлы, не фиксирует изменения и не публикует сайт. Локально на Mac mini 17.10.2026: **0 advisories** в npm production и **0** в Composer locked. Это не означает проверку всех dev-зависимостей или отсутствие будущих уязвимостей. Реальные окна обновлений, контроль лицензий и порядок экстренного выпуска утверждает музей.
