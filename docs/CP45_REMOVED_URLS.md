# CP-45D — инвентаризация адресов, исчезающих из новой версии

16 октября 2026 · №0372200172326000015 · доконтрактная функция проверки, **не** боевой модуль перенаправлений и **не** согласование заказчиком.

## Функциональность

- Сравнение версий CP-44D в закрытой CMS дополнено разделом **«Адреса, которые требуют решения»**. Для исчезающих в новом CMS-снимке новостей, информационных страниц, экскурсий, выставок, документов и событий показывается **прежний публичный маршрут**, а при наличии ранее опубликованной полной английской версии — отдельный `/en/...` URL. Исчезновение URL означает его отсутствие в следующем снимке; запись в CMS может остаться черновиком. Переименование slug также считается исчезновением старого URL и появлением нового.
- Список вычисляется только при наличии **верифицированного локального** базового снимка CP-44D. Если архива нет или он повреждён, нет ни фиктивных удалений, ни CSV. Разделы таксономии не выдумываются в виде публичных URL (их маршруты зависят от веб-архитектуры).
- Из списка доступна скачиваемая **CSV-ведомость** `GET /admin/museum-content/removed-urls.csv`: колонки «Старый URL», «Язык», «Сущность», «Материал», «Новый URL (согласовать)» и «Решение редактора». Последние две колонки содержат пустое целевое поле и приглашение к проверке; **автоматически подбирать 301/302-перенаправления нельзя**. CSV — UTF-8 с BOM, разделитель `;` для табличных редакторов.
- Заявленные URL состоят только из ожидаемых публичных типов и валидных slug, не из произвольных полей HTML. Текст названия экранируется для CSV (начальное `=`, `+`, `-`, `@` даже после пробелов) против Excel/LibreOffice formula injection. Сервер не выполняет сетевых запросов.
- HTTP-ссылка защищена существующей авторизацией MoonShine. Отчёт использует ту же построчную ACL, что и CP-44D: назначенные редактору рубрики ограничивают списки страниц, события пока имеют общий ресурс MoonShine. HTTP-ответ с `no-store`, `noindex`, принудительным скачиванием и `nosniff`; при отсутствии базового снимка возвращается 409, без публикуемого списка.
- Ничего не записывается в `apps/web/out`, публикационные файлы, очередь, редакторские записи или настройки веб-сервера. На настоящем сайте музея после контракта предстоит подтвердить старые URL, выбрать конечные URL и согласовать редиректы с заказчиком. Снимок CP-44D — только локальный.

## Проверки

- `MuseumPublicationDiffTest`: 3 дополнительных сценария — исходные RU/EN URL и событие, отсутствие базового снимка и запрет доступа гостя, фильтрация чужих разделов Editor и предотвращение CSV-инъекции.
- Isolated `scripts/qa_cms_browser.py`: реальный браузер через закрытую CMS проверяет CSV по авторизованной сессии наряду с предыдущим сравнением и публичной статической выгрузкой.
- Режим `--preflight-strict` не изменён. Проверка CP-43D уже предотвращает публикацию известных внутренних ссылок на исчезающие CMS-страницы, но **не гарантирует** отсутствие внешних входящих ссылок, проиндексированных URL, закладок посетителей или ссылок в сторонних ресурсах.

Новых зависимостей и платежей нет. TinyMCE не изменён, 0 ₽.
