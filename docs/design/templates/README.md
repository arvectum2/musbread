# Пустые PDF-каркасы 3 концепций

Это НЕ разработанные варианты логотипа и НЕ предъявляемые заказчику утверждённые концепции. После интервью требуется подготовить три действительно разные творческие идеи по ТЗ (п. 2.2.1–2.2.2), затем получить решение в письменном виде.

| Каркас | HTML источник | PDF (5 листов А4 альбомный) |
|---|---|---|
| Направление 01 | musbread_concept_01_TEMPLATE.html | musbread_concept_01_TEMPLATE.pdf |
| Направление 02 | musbread_concept_02_TEMPLATE.html | musbread_concept_02_TEMPLATE.pdf |
| Направление 03 | musbread_concept_03_TEMPLATE.html | musbread_concept_03_TEMPLATE.pdf |

Содержимое одинаково по критериям сопоставления: исходная гипотеза, аудитория/смысл, RU/EN логотип, палитра/система, носители/выбор. Визуальные акценты — исключительно служебное различие шаблонов, они не определяют цвета будущего бренда.

Генератор — apps/web/scripts/build_concept_templates.mjs. На Mac mini выполнить из apps/web: node scripts/build_concept_templates.mjs. Для PDF использован установленный Chrome/Playwright без Docker и платных подписок. При локальной проверке все 3 PDF открывались как 5 страниц; первый лист визуально проверен после растеризации, текст не выходит за границы страницы.

До показа заказчику заменить placeholders, проверить векторные и растровые исходники, права на изображения/шрифты, напечатать/просмотреть все страницы и согласовать способ передачи/презентации.
