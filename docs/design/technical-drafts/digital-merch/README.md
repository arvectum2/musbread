## Холсты — рабочие гипотезы, не утверждённые размеры

Цифровая афиша 1280×720 px; аватар VK 1024×1024; обложка VK 1920×768; рубрики 1080×1080; схемы девяти сувениров 1280×900.

Это холсты для демонстрации геометрии, а НЕ доказательство соответствия действующим нормам VK и НЕ физические размеры сувениров. Обозначенная в обложке область мобильного кадрирования условная, проверка в реальном VK не проводилась. У сувениров нет производственных развёрток, печатных допусков, CMYK-профилей и реальных растров 300 dpi.

Рубрики пронумерованы 1–4, так как музей ещё не предоставил реальные названия. У каждого сувенира свой схематический контур и зона нанесения, которые нельзя считать согласованными. Все файлы явно маркированы как черновики.

## Проверка на Mac mini

Из корня репозитория:

    /tmp/musbread-design-tools-venv/bin/python scripts/generate_digital_merch_carriers.py
    /tmp/musbread-design-tools-venv/bin/python scripts/generate_digital_merch_carriers.py --verify
    /tmp/musbread-design-tools-venv/bin/python -m unittest tests.test_generate_digital_merch_carriers -v

Используется бесплатный нативный rsvg-convert без Docker. Верификатор проверяет редактируемость структуры SVG, PNG-размер и SHA256, а не коммерческую готовность дизайна.

Для заключительной сдачи потребуются: официальный VK и требования к обрезке, четыре названия рубрик, фото/контент с правами, утверждённый фирменный стиль, модели девяти изделий, технология нанесения, физические размеры, утверждение ЛПР, доказательства редактируемости финальных исходников.

По-прежнему 0 из 113 окончательных бренд-носителей утверждено музеем. Эти технические файлы не могут служить доказательством готового дизайна.
