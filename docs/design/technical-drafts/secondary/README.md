# CP-31D — нейтральные основы музейных и офисных носителей

Внутренний предконтрактный прототип, НЕ утверждённый музеем фирменный стиль. Типы носителей соответствуют оригинальной матрице ТЗ закупки №0372200172326000015, пункты TZ-043–053.

| ID | ТЗ | Вид | Пример под обрез, мм |
|---|---|---|---|
| SIGN-IN | TZ-043 | Указатель входа | 300×150 |
| SIGN-OUT | TZ-044 | Указатель выхода | 300×150 |
| LABEL | TZ-045 | Этикетка экспоната | 100×70 |
| ANNOTATION | TZ-046 | Аннотация | 210×148 |
| OFFICE-BLANK | TZ-047 | Бланк | 210×297 |
| TICKET | TZ-048 | Билет | 180×70 |
| CARD-1 | TZ-049 | Визитка горизонтальная | 90×50 |
| CARD-2 | TZ-049 | Визитка вертикальная | 50×90 |
| BADGE-1 | TZ-050 | Бейдж горизонтальный | 85×55 |
| BADGE-2 | TZ-050 | Бейдж вертикальный | 55×85 |
| INVITATION | TZ-051 | Приглашение | 148×210 |
| THANKS | TZ-052 | Благодарность | 210×297 |
| GREETING | TZ-053 | Открытка | 148×105 |

Все размеры под обрез в таблице — ПРЕДЛОЖЕНИЕ. ТЗ перечисляет обязательные виды, но не утверждает эти физические размеры. Универсальные вылеты 3 мм и внутренние зоны от 5 до 12 мм также предварительные. Перед печатью нужны реальные условия типографии.

Каждому SVG соответствует отдельный векторный PDF с проверкой физического размера MediaBox. В SVG отдельные текстовые объекты, направляющие, линии реза, редактируемые стрелки и заполнители изображений. Не используются реальные имена, персональные данные, музейные цены, фотографии, лицензируемая графика или действительные QR-коды. PDF пока не CMYK-мастер и не сертифицированный 300dpi растр.

Генерация и верификация на Mac mini:
    /tmp/musbread-design-tools-venv/bin/python scripts/generate_secondary_carriers.py
    /tmp/musbread-design-tools-venv/bin/python scripts/generate_secondary_carriers.py --verify
    /tmp/musbread-design-tools-venv/bin/python -m unittest tests.test_generate_secondary_carriers -v

После интервью нужны действительные музейные исходники, габариты носителей, цены и поля билета, маршруты указателей, права на графику и шрифты, согласование типографии, проверка редактируемости в целевом ПО и письменное утверждение. Согласованных позиций в реестре DESIGN_DELIVERABLES.csv по-прежнему 0/113; вспомогательные TECH_ файлы не считаются официальными доказательствами сдачи. Расходы 0 ₽, без Docker.
