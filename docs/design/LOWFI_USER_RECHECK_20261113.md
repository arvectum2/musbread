# Повторная проверка low-fi: главная и главные страницы разделов — 13.11.2026

**Основание:** пользователь проверил 12 пунктов раздела «Главная» подписанного ТЗ. Выявлены: п. 7 (в футере отсутствует графический логотип и название), п. 12 (нет блока других документов и баннеров о ПДн), а также некорректная иерархия навигации (кнопки семи разделов открывали списки вместо самостоятельных страниц разделов).

**Figma:** https://www.figma.com/design/knyDeB1oUERhp2Ab6Wvo5L/Musbread_low-fi_UX_20261103

## Изменения футера

- В каждый из 213 видимых пользовательских экранов и шесть мастер-образцов вставлен графический знак из существующего low-fi и отдельная полоса «Музей Хлеба · Санкт-Петербург»; полное юридическое название сохранено.
- Добавлена секция «Документы, персональные данные и уведомления» со сведениями о политике, персональных данных, согласии и переходом к официальным документам.
- Добавлен явный cookie-баннер с кнопками «Принять» и «Настройки», реализовано шесть демонстрационных overlay-состояний D/T/M. Это только UX-модель, реальное хранение согласия и отзыв не реализованы.
- Существующие контакты, оценка работы музея, политика, подписка и социальные сети сохранены.

## Изменения главных страниц разделов

- Семь разделов — Музей, Посетителям, Афиша, Экскурсии, Детям, Выставки, Наука — получили собственные обзорные страницы для desktop, tablet и mobile (21 экран).
- Каждая: самостоятельный заголовок, вводный текст, место для профильной фотографии, тематический блок, три ключевых направления, актуальное содержимое, ниже список подразделов.
- В desktop шапке **клик по названию** раздела ведёт на его обзорную страницу. **Стрелка справа** отдельно открывает выпадающий список подразделов.
- В меню tablet/mobile выбор основного раздела тоже ведёт на обзорную страницу. Карта сайта сохранена лишь как вспомогательная навигация.
- 39 обязательных подразделов по ООЗ сохранены, с уникальными переходами и доступом с обзорной страницы.

## Открытые требования

- Соответствие законодательства по персональным данным, состав и текст документов, реальная логика принятия и отзыва cookie-согласий требуют отдельной проверки и реализации. Факт существования блока в low-fi не подтверждает правовую готовность.
- Реальные фото, даты, музейные материалы и иные данные оставлены для наполнения музеем.
- Повторное письменное согласование low-fi отсутствует; UX-тестирование и high-fi не завершены.
- Исходный технический светофор 85/118/122 не пересчитывался, production NO-GO.

**Следующий шаг:** продолжить построчное ревью по остальным разделам, затем экспортировать три редакции low-fi для согласования.
