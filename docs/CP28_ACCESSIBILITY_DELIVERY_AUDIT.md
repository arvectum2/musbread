# CP-28D — сплошной аудит доступности и комплектности сдачи

16.10.2026. Предконтрактный QA по закупке №0372200172326000015. **Не является актом приёмки, сертификатом ГОСТ/PDF-UA, заключением по ПДн или передачей исключительных прав.**

## Автоматическая часть

- [x] Скрипт scripts/audit_accessibility_content.py проверяет каждый файл HTML экспортированного Next.js, а не только выбранные страницы axe-core: язык, main, H1, skip-link, alt, названия полей, уникальность ID, опасные ссылки, метаданные, noindex.
- [x] Проверяет опубликованный JSON: полноту EN, alt медиатеки, подписи и типы документов, пути/контрольные суммы SHA-256, отсутствие неутверждённых редакторских заметок.
- [x] Отличает errors от warnings. Unreviewed документ является предупреждением, PDF получает PDF_UA_UNVERIFIED. Режим strict-documents останавливает публикацию при таких предупреждениях.
- [x] Выдаёт отчёт JSON/Markdown. Отдельные unit-тесты подбрасывают умышленно плохой HTML, отсутствие alt, раскрытие черновика и подмену документа.
- [x] Исправлена глобальная 404: Next.js global-not-found выводит русский html lang, meta noindex, H1, main, skip-link и ссылку возврата. Проверяется Playwright + axe-core.
- [ ] Проверка интерфейса в скринридерах и с реальными пользователями, 200% масштаб в нативном Safari/Chromium-GOST, полный ГОСТ Р 52872-2019 и PDF/UA/ГОСТ Р 70176-2022 — отдельно после предоставления файлов и инфраструктуры заказчика.

## Комплектность и руководство посетителю

- [x] Скрипт scripts/audit_delivery_readiness.py читает полный реестр 325 требований; проверяет наличие 17 подготовленных технических файлов/шаблонов и не приравнивает их наличие к приёмке.
- [x] 16 внешних условий (интервью, утверждённый фирменный стиль, авторские права, реальные материалы и переводы, законная обработка ПДн, билеты, инфраструктура, AV/CDR, доступные PDF, QA, пентест и акты) остаются НЕПОДТВЕРЖДЁННЫМИ независимо от CI.
- [x] Написана самостоятельная предварительная инструкция посетителю docs/handoff/VISITOR_GUIDE_DRAFT.md; TZ-316 повышено из Нет до Частично, потому что финальное руководство заказчик ещё не принимал.
- [x] Скрипты работают локально без сетевого обращения, сохраняют отчёты в /tmp и отдельные CI-артефакты. Не включают реальную клиентскую БД/ПДн.
- [ ] Официальная печать/передача, подписанные акты, утверждение фактических сервисов, права на итоговые исходники, проверка на серверах музея — открыты.

## Воспроизведение на Mac mini

Из корня репозитория:

    python3 scripts/audit_accessibility_content.py apps/web/out --snapshot apps/web/src/data/published.json --json /tmp/musbread-static-content-audit.json --markdown /tmp/musbread-static-content-audit.md
    python3 scripts/audit_delivery_readiness.py --require-complete-drafts --json /tmp/musbread-delivery-readiness.json --markdown /tmp/musbread-delivery-readiness.md
    python3 -m unittest discover -s tests -q

Текущий демонстрационный снимок не содержит настоящих PDF или проверенного клиентского контента. Нулевое число ошибок этого частичного статического аудитора НЕ подтверждает соответствие государственным стандартам.
