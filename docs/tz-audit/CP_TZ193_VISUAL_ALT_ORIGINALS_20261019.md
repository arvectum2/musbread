# CP-TZ193-04 — визуальная проверка оригинальных фотографий и описания для экранного доступа

**19 октября 2026 года. Локальный предконтрактный прототип на ArvectumSSD; без публикации, договорной приёмки и согласования музейных подписей.**

## Источники и подход

Проверены фактические пиксели **125 уникальных музейных фотографий** из архива, привязанного к 259 подтверждённым оригинальным фото-URL музея. Для ручного осмотра построены 6 контактных листов на Mac mini (приватная папка `.local_archive/alt_contact_sheets/`). Это фотографии из сохранённых исходников музея, а не найденные в интернете похожие изображения.

По **112** файлам удалось написать краткие предметные описания видимых объектов: витрины, интерьеры, хлебные изделия, занятие с детьми, музейные предметы, пандусы и подъёмные платформы. Данные находятся в `apps/web/src/data/official-museum-reviewed-alt.json` с признаком **DRAFT_FOR_MUSEUM_REVIEW**. Это наши наблюдения по изображениям, НЕ цитаты музея или утверждённые музейные названия экспонатов.

При формировании страницы программа сохраняет реальное непустое смысловое музейное описание, если оно уже есть. При пустом `alt` или техническом импортированном обозначении вида «— фотография 3» подставляется визуально проверенный черновик по **конкретному SHA-связанному WebP**, а не по индексу в галерее. Длинные содержательные музейные подписи не обрезаются, названия и реквизиты экспонатов не сочиняются. Кнопка открытия фотографии тоже получает понятную подпись. Пиксели, исходные URL, фотографии и архивные документы неизменны.

## Контрольная динамика

| Метрика | До этапа | После этапа |
|---|---:|---:|
| Автоматические ALT_POLICY замечания (вхождения) | 293 | **50** |
| Сокращение замечаний | — | **243 / 82,9%** |
| HTML в полном аудите | 945 | **945** |
| Файлы с нерешёнными ALT_POLICY | 125 уникальных | **18 уникальных** |
| Страницы с нерешёнными ALT_POLICY | 56 | **28** |
| Визуально подготовленные предметные подписи | 0 | **112** |
| Исходные музейные URL без привязки | 0 | **0** |

В оставшихся 50 срабатываниях есть важные исключения. Например, исторические музейные атрибуции фарфоровой супницы или кондитерских обёрток превышают локально выбранный порог 125 символов, **но являются содержательными подписями и не должны автоматически усекаться**. Также «График работы музея» описывает официальный плакат, хотя строгое регулярное выражение аудитора распознаёт слово «график» как потенциально пустое описание. Сканы объявлений с мелким текстом надо оформлять для доступного чтения отдельно; простое «объявление» не передаёт расписание. Эти случаи остаются в очереди редакторской и пользовательской проверки.

Оригинальные 293 ошибки перечислены в `ORIGINAL_MUSEUM_PHOTO_ALT_REVIEW_20261019.csv`. **Актуальные 50 / 18** с их оригинальными ссылками и целевыми страницами: `ORIGINAL_MUSEUM_PHOTO_ALT_REMAINING_20261019.csv`.
