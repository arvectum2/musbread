# TZ-111/TZ-259 · Проверка настоящих сторонних браузеров на Mac mini

**19 октября 2026 г., pre-award локальная сборка на ArvectumSSD; сервер только 127.0.0.1, реальный музей не затронут.**

Установлены официальные macOS-приложения на внешний диск, через Homebrew Cask; сведения о производителе и версии проверены непосредственно из установленного приложения/движка. Проверка HTTP 200, H1 и отсутствия горизонтального переполнения DOM на четырёх типах страниц.

**Важно:** Firefox WebDriver на macOS headless ограничивает минимальную ширину окна примерно 500 CSS px. Запросы ширины 320/390 фактически получили viewport **500**, поэтому реальный 320/390 Firefox НЕ проверен. Колонки Firefox со звёздочкой обозначают успешное открытие при 500 px, а не при запрошенном 320/390.

На этих маршрутах в каждом браузере заголовок H1 присутствует, DOM overflow отсутствует; реальные пользовательские действия, все элементы доступности и браузерный Page Zoom в каждом из приложений пока не проверены.

Дополнительно: Chromium-GOST проверен ранее на 467 оригинальных HTML и 23 браузерных сценариях; WebKit 185/185 тестов проверен ранее, но это не идентично проверке двух настоящих версий Safari. **Atom НЕ ПРОВЕРЕН**: не подменять доказательство реального запуска выводом о совместимости Chromium.

**Открытые требования:** обе актуальные версии каждого обязательного браузера, нативный Page Zoom 100–200%, поведение настоящего Firefox на 320 px, Edge/Opera/Yandex интерактивность и доступность более широкого набора страниц, согласование исключения Atom/альтернативных испытаний. Никаких ссылок на небезопасные архивы Atom.

**Статус TZ-111/TZ-259: 🟡 частично**, локальный checkpoint установки и смоук-испытаний новых четырёх браузеров выполнен. Приватный протокол: .local_archive/tz111-native-browser-probe-20261019.json и .local_archive/tz111-firefox-native-smoke-20261019.json.
