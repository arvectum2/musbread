## Atom — нельзя установить актуальную безопасную официальную версию

- Официальный сайт разработчика **https://browser.ru/** прямо сообщал: **«С 13 сентября 2024 года Atom перестанет быть доступным для скачивания и обновления»**. Программа прекращена самим разработчиком VK/Mail.ru, а не из-за Mac mini.
- Открытая официальная карточка RuStore для Android `https://www.rustore.ru/catalog/app/ru.mail.browser` и отзывы отмечают недоступность скачивания. Исторические настольные сборки были для Windows, **сборки для macOS не обнаружено**.
- Установка случайных старых `.exe`/APK со сторонних агрегаторов **не выполнялась**: для прекращённого в 2024 году браузера это не безопасное подтверждение актуальной совместимости и Mac mini не исполняет Windows EXE напрямую.
- **Тест в Atom НЕ проводился.** Подмена обычным Chromium, эмуляция user-agent или утверждение «Atom PASS» запрещены. Для формального снятия пункта после договора потребуется решение заказчика, что требование к снятому с поддержки продукту неприменимо, **либо** подтверждённая безопасная Windows/Android-среда с официально предоставленным старым Atom и согласованный сценарий теста.
