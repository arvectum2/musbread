Одинаковые шесть разделов: главная, новости, музей, поиск, виртуальные выставки и доступная среда. Ноль обнаруженных горизонтальных переполнений.

**Edge.** Настоящий официальный Microsoft Edge в видимом окне и с отдельным тестовым профилем Playwright; Page Zoom задавался macOS Command+Plus и Command+0. Проверены фактические devicePixelRatio, CSS viewport, H1, URL и отсутствие горизонтальной прокрутки, при этом CSS-масштабирование не включалось. Исходное активное приложение Safari восстановлено; Edge закрыт. Скрипт: scripts/qa_native_edge_zoom.mjs. Локальный JSON: .local_archive/tz238-native-edge-zoom-20261019.json.

**Firefox.** Предыдущий измеренный нативный прогон 90/90; скрипт scripts/qa_native_firefox_zoom.py, протокол .local_archive/tz238-native-firefox-zoom-20261019.json.

**Safari.** Safari WebDriver и запросы Safari AppleScript к DOM не отвечают, поэтому использовано настоящее приложение Safari в новом одноразовом окне, macOS меню View / Zoom In и Zoom Out, системное API AXUIElement для WebArea, ScrollArea, AXHeading и AXStaticText. Это **не CSS zoom и не Playwright WebKit**. После исправления ошибки исходной методики измерение шло по неизменной короткой ссылке «Перейти к содержимому», а не по многострочному заголовку или логотипу. Фактический размер AX-текста на шести последовательных ступенях: **15, 17, 20, 23, 25 и 29 px** во всех 18 сочетаниях страниц и ширин. Таким образом наблюдается практически двукратное увеличение, но Safari AX **не сообщает точный внутренний процент**; для Safari корректно заявлять примерно 100–200%, а не точно измеренное значение 200%.

Итог Safari: **108/108 измерений PASS**, WebArea и ScrollArea имеют одинаковую ширину, горизонтального AXScrollBar нет, заголовки и ссылка пропуска к содержимому доступны. Текущий скрипт компилирует Swift-модуль исключительно на ArvectumSSD: scripts/qa_native_safari_ax_zoom.py + scripts/qa_native_safari_ax_metrics.swift. JSON: .local_archive/tz238-native-safari-ax-zoom-20261019.json.

Особо проверена безопасность рабочей сессии: Safari запоминает Zoom локального тестового сайта между окнами, поэтому скрипт после каждого маршрута восстанавливает исходный размер AX-текста 15 px, а после полного прогона закрывает только своё временное окно. Число окон **2 до → 2 после**, исходный Safari остался активным. VoiceOver выключен, тестовые HTTP-серверы остановлены. Чужие вкладки, рабочие браузерные профили и сайты не менялись.

Предыдущие предварительные прогоны Safari имели ложные ошибки: проверялась высота крупного H1 главной или длинного музейного логотипа, который переносился при узкой ширине. Исправленная проверка короткого общего AXStaticText завершилась 108/108. Эти предварительные ложные срабатывания не объявлялись успешными.

## 2. Доступность и границы

Настоящее дерево доступности Safari содержит заголовки, ссылки, навигацию и ссылку пропуска к содержимому; это весомее одной эмуляции WebKit. Однако **фактическое чтение музея программой VoiceOver НЕ подтверждено**: ранее приложение удалось запустить и выключить, но команды получения произнесённой фразы/курсора завершились тайм-аутами. Исходные PDF не имеют доказанной доступности для screen reader.

Atom не установлен и не проверен; совместимость Chromium не является доказательством по Atom. Две версии обязательных браузеров, утверждённый дизайн и пользовательская приёмка музеем остаются открытыми. **Дополнительно** реальный Microsoft Edge в графическом режиме прошёл полноценный клик по кнопке поиска «Показать все результаты». Кадровое обновление RAF=true, появилась ссылка на ожидаемую демонстрационную новость (/news/demo-news/), факт пользовательского pointer.click PASS. Сценарий проверен отдельно скриптом scripts/qa_native_edge_pointer_search.mjs, JSON .local_archive/tz259-native-edge-headful-pointer-20261019.json. Прежний headless Edge pointer timeout остаётся фактом тестовой среды, не доказательством дефекта пользовательского сайта. После теста Edge закрыт, Safari снова активен.
