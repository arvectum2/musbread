## Граница подтверждения по исходному ТЗ

**Технический критерий «посетитель может открыть и просмотреть оригинальный PDF» — ЗАКРЫТ (🟢).** Исходный текст **п. 2.2.3.6.5** помимо этого прямо требует читаемости официальных документов *экранными дикторами* и PDF с машиночитаемой структурой **либо** доступной HTML-альтернативы. Этот дополнительный нормативный критерий **не следует из успешного показа PDF**. Не подменять `PDF отрисован` на `PDF доступен программам экранного доступа`.

В существующей матрице TZ-211 и TZ-212 теперь **🟡**, поскольку сам сайт выдаёт все документы правильно, но условия для экранных дикторов не подтверждены. **Документы оставить без изменений, больше не инициировать OCR и переработку архивных сканов.** Если при заключении договора заказчик уточнит применимость требований к отдельным официальным документам, трактовку согласовать отдельно; заранее новые работы не создавать.
