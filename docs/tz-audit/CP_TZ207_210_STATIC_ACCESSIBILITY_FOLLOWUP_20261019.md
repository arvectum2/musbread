# TZ-207–210 / TZ-193 · Аудит всех 945 HTML и исправление клавиатурных дефектов

**19.10.2026, изолированная локальная сборка; документы PDF не преобразованы, не OCR.**

Существующий полный HTML-аудит scripts/audit_accessibility_content.py прогнан на всех 945 HTML после полной защищённой сборки. Первое измерение: **760 замечаний ошибок** = 88 страниц без main/h1/viewport/main id, 115 страниц без skip-link (88 fallback + 27 реальных индексных страниц), 293 замечания ALT_POLICY. Число 760 — сумма вхождений ошибок, а не число уникальных адресов.

Исправления:

1. В генераторе 88 старых /node/N fallback-страниц добавлены обязательные html viewport, main id, один H1 и клавиатурная ссылка «Перейти к основному содержимому». Эти страницы обычно реально отдают **HTTP 301 через Nginx**; исправлен также безопасный fallback для не-Nginx-размещения. SEO noindex/meta-refresh и точный проверенный destination не изменены.
2. В генераторе 27 оригинальных архивных /novosty?page=N добавлен skip-link. Это **настоящие страницы HTTP 200**, в отличие от fallback.
3. Сопутствующее исправление: генератор старых URL безопасно распознаёт собственный точный HTML после штатного удаления приватных marker-файлов из release. Неизвестные, не совпадающие байт-в-байт HTML остаются ошибкой коллизии. Старые SEO пути/redirect map не менялись.
4. Unit-тесты защищают H1/main/skip-link/viewport на всех 88 fallback и 27 архивных страниц.

После полной сборки и повторного аудита **293 ошибки и 10 предупреждений** вместо **760 ошибок и 10 предупреждений**.

**293 оставшихся ALT_POLICY** охватывают **56 различных HTML-страниц** с исходными музейными фотографиями. Примеры: «Колобок — фотография 1», «График работы музея». Не все такие описания бессмысленны; текущий regex строг и ловит слово «график» в нормальном содержательном названии. Однако автоматически заменять alt придуманными описаниями, очищать alt, массово делать OCR и выдавать доступность за доказанную нельзя. Требуется отдельный source-first фотосмысловой аудит/согласование контент-редактора; возможна классификация декоративных кадров после UAT. Эти 293 автоматических замечания **не объявлены исправленными**.

Параллельные гейты: preview robots «Disallow: /», noindex и пустой sitemap **PASS**; аудит тяжёлого UI проверил 945 страниц, 20 JS файлов (927615 байт), 303 медиа, критических отклонений **0**. Отдельные требования PDF screen reader, реальный Page Zoom, WCAG/ГОСТ и приёмка музеем не закрыты.
