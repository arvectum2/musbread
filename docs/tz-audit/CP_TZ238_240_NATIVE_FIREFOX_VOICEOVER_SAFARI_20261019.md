# CP-TZ238/240/259 · Настоящий Page Zoom Firefox, VoiceOver и Safari

**19.10.2026, Mac mini macOS 27.0.1, монитор 1920×1080.** Действующий сайт, DNS, robots, CMS заказчика, исходные PDF не затронуты. Предконтрактный локальный стенд 127.0.0.1 на ArvectumSSD, без публикации и без юридической/пользовательской приемки.

## 1. Реальный Page Zoom официального Firefox 158.0

Через одноразовый GUI-профиль geckodriver и **НАСТОЯЩИЕ системные команды macOS Command+Plus / Command+0** проверено изменение масштаба Firefox. Это НЕ CSS zoom, НЕ CSS transform и НЕ эмуляция ширины страницы вместо браузерного увеличения. Скрипт ждёт фактически установленного devicePixelRatio, сравнивает CSS viewport и root scrollWidth, H1 и URL.

| Измерение | Значение |
|---|---|
| Разделы | Главная, новости, музей, поиск, виртуальные выставки, доступная среда |
| Ширины окна | 1280, 1024, 768 px |
| Пять уровней zoom | 100%, 120%, 150%, ~170%, 200% |
| Количество случаев | **90** |
| Реальный Zoom, H1, URL | **90/90 PASS** |
| Горизонтальное переполнение | **0/90** |
| Фактические browser DPR | 1.0; 1.2; 1.5; 1.714; 2.0 |
| CSS viewport на ширине 768 px при 200% | **384 px**, во всех шести разделах |
| GUI после теста | Исходный Safari восстановлен; одноразовый Firefox закрыт |

Код проверки: scripts/qa_native_firefox_zoom.py. Evidence: .local_archive/tz238-native-firefox-zoom-20261019.json и .local_archive/tz238-native-firefox-zoom-20261019.log. Добавлено 6 регрессионных unit-тестов, запрещающих принимать CSS-подмену, неправильный Zoom, чужой URL или overflow за PASS. Первый быстрый прогон принимал асинхронные промежуточные значения zoom за ошибки; методика исправлена на ожидание фактического уровня и повторена, итоговый второй прогон **90/90 PASS**.

**TZ-238 и TZ-240 остаются частично выполненными**, поскольку еще нет финального согласованного дизайна и проверок на всех обязательных браузерах/устройствах музея. Старые 90 Chromium также PASS; это другое семейство сборки.

## 2. VoiceOver: запуск есть, сценарий чтения не пройден

В графической сессии Mac mini настоящее приложение VoiceOver из стандартного macOS пути запускалось. До запуска процесс был выключен. Установлено AXIsProcessTrusted() = true. Однако запросы AppleScript текста под курсором и последней произнесённой фразы дважды завершились тайм-аутом. Нет подтверждённого текста, прочитанного VoiceOver с музейных страниц. **НЕЛЬЗЯ утверждать, что проверка экранным диктором пройдена.**

После попытки VoiceOver выключен; pgrep не находит процесса, исходное состояние восстановлено. Evidence: .local_archive/tz193-voiceover-start-stop-20261019.json.

Для закрытия требуется реальный GUI-сеанс с проверкой чтения заголовков, навигации по ссылкам, полного описания изображений, текстовых архивных афиш, поиска, клавиатуры и исходных PDF вместе с ответственным за приёмку.

## 3. Safari, Edge и WebKit

**Safari 27.0.1** отвечает на запрос версии, но AppleScript-запрос окон зависает, а safaridriver не смог создать тестовую WebDriver-сессию. Нативный Safari Zoom и VoiceOver в Safari **не подтверждены**.

**Движок Playwright WebKit:** отдельно пройдены **15/15 тестов доступности** (accessibility, not-found-accessibility, tz197-240-accessibility). WebKit НЕ эквивалентен реальному Safari и НЕ является доказательством чтения VoiceOver. Лог: .local_archive/tz238-voiceover-webkit-accessibility-backstop-20261019.log.

**Microsoft Edge 155:** в графическом режиме отдельным коротким тестом действительно измерены уровни Zoom 100 → 110 → 125 → 100% с изменением devicePixelRatio и CSS viewport. Однако полный многомаршрутный Edge 100–200% **НЕ проводился успешно**, его нельзя считать PASS. Ранее headless Edge проходил поиск клавишей Enter, но pointer-клик ожидал RAF и не был подтверждён.

Atom не установлен и не проверен; требуется формальное решение заказчика. В другом браузере семейства Chromium совместимость Atom не доказывается.
