- Подтверждён реально работающий процесс VoiceOver (PID 48986); не эмулятор.
- В новом временном Safari-окне открыт локальный сайт музея по адресу 127.0.0.1, маршрут /guide/museum/, получен ожидаемый заголовок «Музей | Музей Хлеба».
- Три команды настоящей VoiceOver-навигации Control+Option+Right отправлены через System Events, исполнены без ошибок macOS.
- Временное Safari-окно закрыто, исходные два окна пользователя сохранены, локальный HTTP-сервер остановлен.
- Команда штатного выхода из приложения VoiceOver успешно выполнена, процесс отсутствует (pgrep -x VoiceOver пуст).
- После выхода из VoiceOver настройки звука повторно подтверждены: output volume:0, output muted:true. Громкость не восстанавливалась и не повышалась.

## Ограничение: фактическое чтение не доказано

AppleScript-запросы текста последней произнесённой фразы и содержимого VoiceOver-курсора вернули ошибку -1728, а команда web overview — -1708. Системный глобальный AXFocusedUIElement в этой сессии не получен.
