# CP-50D — сводка открытых редакторских вопросов

16 октября 2026 · закупка №0372200172326000015 · внутренний доконтрактный прототип, не приёмка музеем.

## Сценарий

В приватном MoonShine «Материалы → Сравнить → Замечания и решения по версии» появился блок **«Сводка редакторской проверки»** со счётчиками «Требуются исправления», «Есть замечания», «Ещё не рассмотрено», «Проверено внутри команды». Ниже расположен отсортированный список **вопросов, требующих внимания**: сначала незакрытые `needs_changes`, потом `comment`, затем `unreviewed`, со ссылками на конкретную запись в журнале.

Источником служат только **изменённые** объекты в текущем локальном сравнении (новые, изменённые, исчезающие), с учётом уже установленных прав CP-49D. Неизменённые объекты не требуют очередного рассмотрения, а старые решения к другим SHA-256 не учитываются. Текущим внутренним состоянием считается **последняя** append-only запись по ID в паре `baseline_sha256` и `candidate_sha256`. Если последняя запись — `checked`, пункт уходит из списка внимания; новое замечание снова открывает его. При изменении снимка все решения к предыдущей версии остаются только в истории.

## Безопасность и ограничения

- Сводка вычисляется из **того же ACL-ограниченного списка и набора заметок, которые уже доступны контроллеру**, без отдельного запроса ко всем материалам или счётчиков по чужим разделам. Редактор видит только свои текущие материалы; admin — материалы, события и структуру. Отозванные гранты и перенесённые объекты не участвуют.
- Блок доступен только внутри приватной страницы с `no-store`/`noindex`/CSP. Названия/ключи выводятся Blade-экранированием. Ссылки на элементы формируются из безопасного фиксированного SHA-256 ключа; в HTML не попадают произвольные `id` из CMS.
- **«Проверено внутри команды» не означает утверждение заказчиком.** Нулевое число открытых вопросов не отменяет контрактную приёмку, preflight, отдельные права на документы, проверку юридической достоверности и ручные решения по перенаправлениям. Сводка не запускает экспорт, не изменяет CP-47D, не создаёт редиректы и не выпускает материалы.
- Статусы представляют собой внутренние заметки, а не автоматический процесс закрытия задачи или гарантию готовности технического сайта. Новых миграций, ролей, платных сервисов и редакторов HTML нет: TinyMCE без изменений, 0 ₽.

## Контроль качества

- `MuseumEditorialReviewSummaryTest`: оба порядка смены решений, нерассмотренные материалы, группировка, приоритет «исправить → замечание → не рассмотрено», игнорирование чужих и неизменных ключей, пустая выборка.
- `MuseumPublicationDiffTest`: HTTP-страница с состояниями, изменение `needs_changes → checked → needs_changes`, обнуление актуальных отметок при новом content SHA, проверка отсутствия чужих счётчиков Editor и неизменность очереди публикаций.
- Изолированная Playwright-проверка CMS CP-48D теперь дополнительно проверяет блок сводки до и после настоящего POST. Полный PHPUnit, 27 public E2E, 12 тестов архива/отката и CI.

Открыто после контракта: клиентское интервью, согласование ролей, правила официальной приёмки и дополнительные права на афишу.
