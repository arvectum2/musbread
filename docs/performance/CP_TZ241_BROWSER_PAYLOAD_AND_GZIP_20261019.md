# CP-TZ241-02 — ускорение загрузки музейного сайта

**Проверено 19.10.2026 на Mac mini, ArvectumSSD.** Основание: TZ-241 (п. 2.2.3.8.1, загрузка до 3 секунд на большинстве устройств), TZ-135 (новости), SEO сохранность оригинальных страниц. Измерения — исключительно на локальном стенде, без доступа к серверу заказчика.

## Снята лишняя нагрузка с JavaScript

OfficialMuseumNightArts теперь состоит из серверной части, которая обрабатывает оригинальный текст и HTML через существующий серверный RichText, и небольшого клиентского компонента OfficialMuseumNightArtsDisplay, который обновляет даты и отображение. Огромные архивы JSON, библиотека sanitize-html и музейные изображения не отправляются как клиентский JavaScript только ради карточки одного события.

Самый тяжёлый JS-модуль сократился **с 910 928 байт до ~86 КиБ**, около 90%. Содержимое музейного анонса от 16.10.2026, дата мероприятия 03.11.2026, источник и поведение после даты события сохранены. После рефакторинга p75 полного load у /guide/museum/ на медленной лабораторной сети сократился **9490 → 4687 мс**, но критерий 3 с не выполнен.

## Устранено дублирование архивных новостей

Ранее /news/ содержал полные тексты всех 270 архивных новостей прямо в 270 карточках списка, в дополнение к отдельным 270 исходным HTML-страницам. Теперь список содержит заголовки, даты, проверенные музейные изображения, анонсы и ссылки на полные тексты. Первые 10 новостей по-прежнему можно раскрыть непосредственно из списка. Полные 270 архивных статей по прежним URL и 27 исторических страниц пагинации остались без изменений.

**Размер out/news/index.html: 1 528 983 → 1 039 197 байт (−32,03%).** В условиях холодного Chrome, CPU×4, 150 мс RTT, 1,6 Mbps p75 load страницы новостей снизился **11 245 → 8 779 мс** (без gzip); промышленное требование 3 с НЕ подтверждено.

## Nginx gzip и проверенные результаты

В шаблоны изолированного Nginx и будущего публичного контура добавлены gzip on, gzip_vary on, gzip_min_length 1024, gzip_comp_level 5 и типы CSS/JS/JSON/XML/SVG. PDF/DOCX и оригинальные фото не менялись. Проверка через настоящий локальный Docker Nginx требует заголовок Content-Encoding: gzip.

Полная HTML-страница /news/ на локальном Nginx реально передаётся в **111 759 байтах** (экономия трафика около 89,25% относительно несжатого HTML). Это НЕ пользовательские сетевые испытания музея.

## Проверки

- Полная офлайн-сборка PASS: 101 PDF/DOCX (исходные SHA-256), 259 исходных фото-URL и 255 локальных WebP, 27 страниц пагинации и 280 настоящих новостей.
- 12 модульных Python тестов PASS, включая полноту всех 270 страниц старых архивных новостей и отсутствие дублирования полных текстов в главном индексе.
- 5 настоящих Playwright browser E2E PASS: новости, событие, исходный HTML, мобильная ширина 320 px.
- Nginx -t PASS, 881/881 одношаговых HTTP 301, 467/467 исходных HTML, 27/27 архивных пагинаций, 101 документ, 303 WebP PASS. 96/96 PDF по прежним путям корректно отдаются inline и рендерятся без OCR.
- Полный холодный лабораторный p75 load без gzip через Python http.server ПОСЛЕ обеих оптимизаций: главная **4005 мс**, новости **8779 мс**, музей **4680 мс**, поиск **3913 мс**. LCP p75 около 1,53–1,56 с. Условие ТЗ «не более 3 секунд на большинстве устройств» НЕ подтверждено.

**Результат:** внутренний этап CP-TZ241-02 выполнен, но **TZ-241 остаётся 🟡 частично** до испытаний на согласованном сервере музея с реальным HTTPS/Nginx, сетью, окончательной вёрсткой, устройствами и приёмкой заказчика. Существующий сайт музея, DNS, дизайн и условия индексации не менялись.
