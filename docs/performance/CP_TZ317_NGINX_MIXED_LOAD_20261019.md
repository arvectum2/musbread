**19.10.2026, Mac mini ArvectumSSD, Docker Nginx со статическим export, только 127.0.0.1.**

Отдельный, воспроизводимый скрипт: scripts/qa_nginx_concurrent_load.py. Защитные ограничения: только буквально http://127.0.0.1:PORT; не больше 24 одновременных клиентов, не больше 40 циклов по восьми маршрутам, никогда не тестировать боевой сайт. Реальный Nginx, gzip HTML, все файлы release read-only. Каждая смесь охватывала главную, новости, афишу, музей, поиск, исторический /novosty, одну настоящую WebP-фотографию и исходный музейный PDF (HTTP Range, 64 КБ, без полной повторной скачки скана).
