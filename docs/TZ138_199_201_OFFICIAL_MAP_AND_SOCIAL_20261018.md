## Функции

- На /guide/museum-contacts/ и /guide/plan-visit/ интегрирована настоящая музейная карта Яндекса. До нажатия «Показать карту музея» никаких запросов на yandex.ru нет, посетитель видит прямой внешний поиск адреса. После активации появляется iframe музейной карты (title для доступности, loading lazy, referrerPolicy no-referrer, sandbox), при нажатии «Скрыть карту» iframe удаляется. Есть предупреждение, что Яндекс после активации может использовать cookies и обрабатывать технические данные; скрытие карты не утверждается как удаление таких данных.
- Если утверждённый редактором MoonShine адрес изменится, источник карты прежнего адреса автоматически блокируется; остаётся актуализированный поиск нового адреса. Новых сторонних API нет.
- Nginx CSP допускает внешний источник только в frame-src https://yandex.ru; script-src, connect-src и img-src не расширены на Яндекс. Уже существующие жесткие запреты и хеширование inline скриптов сохранены.
- На страницах контактов и планирования визита добавлена отдельная зона «Сообщества музея», ВКонтакте и MAX с официальными ссылками. Такие же ссылки уже есть в шапке desktop/mobile и в футере. Без встроенной социальной ленты, шпионящих JS/трекеров и пассивных сторонних запросов.
- Доступность: кнопка с Enter/Space, aria-expanded/aria-controls, заголовок iframe, отдельная текстовая ссылка; тесты 320px.

## Проверки

Python: точный SID, исходный URL+SHA256, отсутствие геокоординат по догадкам и точные социальные аккаунты, строгий CSP. Playwright: нет обращения к Яндексу до явного нажатия, активация и скрытие iframe, клавиатура, 320px, социальные ссылки header/footer/контакты. Верифицирована Next.js сборка и реальный ответ внешнего виджета HTTP 200.
